### 0.2 已确认的具体方法及参数：受控减速与定点停止

| 检查内容 | 已确认的计算口径 | D | A | U |
|---|---|---|---|---|

- **D-006**　减速平顺性结合纵向杆量与飞机减速度评价。科目一的期望操作是建立适合当前速度和剩余距离的减速输入后大致保持，允许必要的小幅修正和接近停点时的平顺回杆。中段杆位变化范围已按D-007确认；两类证据的合并规则仍见第8.3.3节的讨论方案。
- **D-007（2026-11-09）**　采用“中段杆位变化范围”作为纵向操纵输入的检查量。观察前向速度从主减速段入段速度的80%降到20%的区间，计算 `H = P90(Pilot Lon) − P10(Pilot Lon)`。`H ≤ 20` 为D，`20 < H ≤ 50` 为A，`H > 50` 为U，单位为CSV原始杆量。每趟可选择不同的适当减速杆位，不要求对齐一个固定杆量。该量描述大部分杆位值所占的范围，不能单独区分逐渐调整与反复推拉；结合原始曲线和减速度响应判读。80%→20%及20/50为本项目设定。短时杆量变化 `J` 及最终合并档与P/F不属于本轮确认范围。

### D-001：科目一删除全部高度相关评估

确认日期：2026-11-02。适用场景：SCN-001，加速减速任务。

**用户确认的任务前提：** 本任务主要操纵轴不包括Vertical（垂直）轴，高度应始终保持不变；本任务的所有高度相关检查全部删除。高度恒定作为场景前提，不再作为本任务中需要评价的学员能力。

### D-010：停止点预判与一次到位

确认日期：2026-11-13。适用范围：科目一“受控减速与定点停止”。

**用户确认的评估逻辑：** 熟练的飞行员直接拉杆减速，飞机快停下时回杆，一次停稳在指定区域；停不准才需要再调整，这与熟练度直接相关。再调整时，一方面看飞机实际挪动的次数和幅度，最好是没有任何挪动；另一方面看飞行员为这些修正付出的操纵：朝一个方向给杆后马上松开、飞机基本没有移动的是无效修正，往前又往后、往左又往右的是反复修正，两者都是操纵不熟练的表现。保持住的小杆量会带来微量挪动，属于正常细调。

#### 2.8 与已有决定的关系

- D-003继续有效：首停后为进入停止区的移动允许，不单独判任务失败，它在检查点四中降低档位。
- D-005中“初次停下后为进入停止区而再次前移，归末端位置调整”改由检查点四评价。
- 检查点一（D-004）仍评价最终停点；检查点四评价首次停止点，两者分开记录。
- 一次反复修正在飞机上表现为运动方向反转，在杆上表现为反向输入，只在操纵杆一侧计一次。

#### 2.9 算法参数

| 参数 | 取值 | 依据 |
|---|---|---|
| 首次停止 | 水平地速 ≤0.5 m/s 持续 ≥0.5 s 的起点 | 沿用8.3.2的回放切分口径 |
| 一次挪动 | 单轴速度绝对值 >0.5 m/s 持续 ≥0.5 s | 与首次停止的速度门槛一致 |
| 杆输入 | 杆量绝对值 >5（满量程100）持续 ≥0.05 s | 低于±5的短促变化引起的位移为零，多为手部微颤 |
| 响应观察窗 | 输入结束后2 s，遇下一次输入截止 | 首停后杆→速度的滞后中位数：前后1.65 s、左右1.90 s |
| 无效修正 | 保持 <1 s 且引起位移 <0.05 m | 杆→姿态的滞后中位数：前后0.60 s、左右0.85 s；保持超过1 s的输入使飞机挪动的比例为前后93–100%、左右79–100% |
| 飞机在动 | 速度绝对值 >0.2 m/s，用于区分刹车与反复修正 | 本项目设定 |

## 4. 本轮审查：按技能能力组织item（待确认）

讨论日期：2026-11-02。用户指出，原“加速与保速控制”“平滑减速与定点停止”主要按phase分组，希望从权威标准提炼待评估的飞行员技能能力。

### 4.1 审查结论

- 原前两项作为训练动作／任务段有意义，但与第三项“操纵平顺性与协调”的抽象层级不一致；不宜直接将这三项当作同一层级的通用技能能力。
- FAA ACS本身采用Area of Operation → Task → Knowledge / Risk Management / Skills结构；按动作设置官方考试任务并没有问题。若本项目item旨在表示可跨阶段追踪的技能，应继续提取Task下面的技能要求，明确它是项目能力维度，而不是冒充官方同名考试任务。
- 候选组织方式：科目／场景 → 能力item → 对应阶段的检查点与证据。phase用于说明观察条件、目标和适用范围，不直接决定能力名称。
- EASA FEM Module 1 §15.3列出“Aircraft Flight Path Management, manual control（FPM）”，其可观察行为包括准确、平顺的手动控制，发现航迹偏差并采取适当操作。该能力框架为跨阶段评价提供参考；本项目下列细分不是EASA原文规定的四项独立核心能力。

### 4.3 证据与解释边界

- 任务阶段有不同目标，但可为同一个能力item提供证据，例如速度控制覆盖加速、保速、减速和停止。
- 航迹／定位控制描述飞机在水平面上往哪里运动、最终在哪里；航向控制描述机头朝哪里，二者分别定义。
- 速度、位置、航向结果与操纵质量可能相关。操纵项可使用这些状态解释动作效果，但不能把相同状态误差当成新的独立证据重复强化；具体网络依赖需随检查方法设计。
- 不把动作次数少、杆量小、输入变化率低直接等同于平顺或能力强。
- D-001继续适用：所有候选item及检查点均不在科目一重新引入高度、垂直速度或Vertical轴考核。
- 以上为从权威要求提炼的项目技能维度，不代表已验证它们是四个相互独立的潜在能力，也不代表覆盖官方任务的全部考试要求。

### 5.3 需要保持清晰的边界

- 高度是完整定点悬停的重要组成。这里按水平、垂直和航向分别描述同一动作中的能力维度；不是从悬停要求中删去高度，也不是另加一段高度任务。
- 完整定点悬停的候选完成要求，应在同一保持窗口内同时满足水平位置／运动、垂直高度／运动和航向要求；具体D/A/U、持续时间、P/F及能力融合后续讨论。
- 速度暂作为水平漂移、垂直运动和到点停稳的检查数据，不再单设速度能力item。当前尚无独立的转移速度训练目标，不预设必须按照固定垂直速度或唯一高度—时间曲线完成；若后续明确此目标，再审查是否需要独立速度item。
- 升降途中尚未到达下一目标高度属于正常任务过程，不能逐帧机械以“当前高度减终点高度”判差。移动过程与目标捕获／保持的适用规则应分别定义。
- ①仅使用水平位置／路线偏差，②处理垂直高度／运动，③处理机头航向。避免用XYZ合成距离又重复将同一个高度偏差作为独立证据。
- 四轴控制输入不等同于四个能力item；Vertical是输入，垂直控制能力需要通过相关操作与飞行响应共同观察。不会把本任务控制轴直接等同于传统直升机cyclic、collective和pedals的控制律。
- 操纵项不简单依据动作次数少、杆量小判好坏；复用其他item状态解释动作时需明确相关性，避免独立似然重复计入。
- 若沿用激光靶设计，靶面落点属于辅助观测或可视化，不另命名为一种飞行技能，也不能单独替代位置、高度与航向要求。当前真实CSV没有光点字段，本候选结构不依赖光点才能成立。
- 本场景排除项不能照搬科目一：Vertical、高度及垂直速度在hover场景中保留。上下往返次数、定点保持时间和靶面规则属于项目任务设计，不称为FAA/EASA统一要求。

## 6. 驾照、飞行考试与航校评估的对照调研

调研日期：2026-11-02。目的：弄清训练场景、考试动作、检查要求与能力维度怎样划分，为本项目item的含义与结构提供依据。本节为调研结论与设计建议，不表示用户已确认更换结构。

### 6.1 主要发现

本次核对的驾照和飞行考试按具体操作／动作组织达标检查；飞行训练又可以对能力、熟练程度与是否需要帮助作跨动作评价。具体动作与通用能力有对应关系，不能混用名称，也不必强行只保留其中一层。

前文四个能力item仍为本项目候选，不能描述为FAA/EASA原文的四个核心能力或四个完整考试Task。“按phase组织”与“按动作组织”也不完全相同：一个考试动作可以跨多个phase，一个phase也可能同时提供多种能力证据。

### 6.2 国内小型汽车驾照：科目、项目、具体评判

以C1/C2为例，官方规定先区分知识、场地驾驶与道路驾驶等考试科目，再在场地考试中列倒车入库、侧方停车、曲线行驶、直角转弯等具体项目；C1另含坡道定点停车和起步。道路考试包括直线行驶、变更车道、靠边停车等操作。“科目四”通常指科目三的安全文明驾驶常识部分，法规没有把它另列成第四个考试科目。[公安部令第172号修改后的规定，第30、33、34、35条][exam-car-rule]

| 层级 | 例子 | 意义 |
|---|---|---|
| 考试科目 | 科目二：场地驾驶技能 | 一类考试内容。 |
| 考试项目 | 倒车入库 | 要完成的具体操作。 |
| 专项评判 | 是否出线、入库、完成规定操作 | 这个项目的达标要求。 |
| 通用评判 | 操作规范、安全、制动平顺等 | 跨项目适用的要求。 |

GA 1026-2022第6.2.2和6.2.3分别设置通用与专项评判，例如倒车入库的边界／完成结果，另有转向和制动操作质量要求。它不是先分别生成一份转向能力分和速度能力分，再用二者平均替代考试通过判定。[标准元数据][exam-car-standard] [原文公开副本][exam-car-copy]

来源范围：标准元数据在国家标准平台核对为现行；原文副本由第三方托管，封面写“以正式出版稿为准”，本轮仅以其核对结构与例子，不据此制定各地考试扣分或本项目数值。

### 6.3 FAA：操作领域 → Task → 知识、风险与技能要素

当前FAA官方目录列有2024年生效的直升机私用驾驶员ACS-15。其悬停机动领域再分垂直起降、悬停滑行、空中滑行等Task，每个Task包含知识、风险管理和技能要素；不是将一个Task简化成一个瞬时位置误差。[ACS-15][exam-faa-heli]

Powered-Lift商业级ACS-2的CP.IV.A.S4/S5/S6/S8在同一垂直起降Task下分别提出无漂移、悬停高度、指定位置和航向要求。官方把多项技能要求放入同一动作检验，项目可以据这些要求提炼更细的技能维度。[ACS-2，印刷18页][exam-faa-pl]

| 层级 | FAA示例 | 本项目需要区分的概念 |
|---|---|---|
| 操作领域 | 悬停机动 | 考试内容类别。 |
| Task | 垂直起降、悬停滑行等 | 要完成的动作／程序。 |
| Skills要素 | 位置、高度、航向等具体控制要求 | 可映射为检查点或技能维度的依据。 |
| 本项目能力节点 | 例如水平定位能力 | 按研究目的提炼的模型变量，并非原文Task名称。 |

官方失败原则也不只看数值：ACS-15附录1同时关注安全干预、持续超差和未及时纠正。需要区分误差、过程、修正和安全后果，不能由这一原则自行编出统一恢复秒数。[ACS-15附录1，印刷54页][exam-faa-heli]

### 6.4 EASA：考试项目与跨项目能力指导并存

AMC2 FCL.235的PPL(H)测试按飞行前／后程序、悬停与相关操纵、导航、飞行程序与机动、异常和应急等Section组织，下面再列定点悬停、悬停转弯、前后侧移等项目。其一般评价还涉及平顺准确与飞行控制。[官方在线2023修订存档][exam-easa-test]

FEM Module 1 §15.3另列手动航迹管理、程序应用、情境意识、工作负荷管理等能力，便于跨动作复盘。该表明确不改变Part-FCL适用测试的P/F标准；速度、位置、高度和航向不是该表中的四个独立核心能力。[FEM，印刷27–29页][exam-easa-competency]

这说明本项目可以区分“动作是否达标”与“这次表现支持怎样的能力判断”。知识、风险、情境意识等需要对应证据，不能仅从位置、速度或操纵杆活动自动宣称已评估。

### 6.5 三所航校／训练机构的公开实例

### 6.6 官方教员评估指导补充

FAA《Aviation Instructor's Handbook》第6章将动作／程序学习与单人资源管理使用不同评价框架。动作学习考虑能否描述、理解、在指导下练习、独立完成，并单列未观察；独立完成还包括及时发现与纠正错误。[第6章，6-5至6-7][exam-faa-assessment]

可借鉴“独立完成程度”和“纠偏质量”。但无教员的仿真若要评价帮助依赖，需要记录系统提示／辅助等对应证据；不能凭轨迹数值擅自推断。这里的学习等级不是本项目D/A/U三档，也未提供贝叶斯CPT。

### 6.7 对当前系统的候选建议

建议在方案中同时保留并明确以下概念：

| 概念 | 回答的问题 | 科目二的例子 |
|---|---|---|
| 训练场景 | 这次安排了什么练习？ | 斜飞到点，再上下点转移与定点保持。 |
| 动作／要求及其来源 | 要完成哪些受检验的动作？参考哪条标准？ | 定点保持参考悬停要求；两个空中点之间的升降为场景适配。 |
| 检查点 | 哪些实际证据说明动作达到要求？ | 水平定位、高度、航向、稳定状态和适当操纵等。 |
| 能力维度 | 这些证据支持怎样的技能判断？ | 水平定位、垂直控制、航向和操纵质量等候选能力。 |

如果最终决定item表示能力，可保留第4、5节的能力item方向，并增加清楚的动作—标准—检查点—能力映射。若希望item直接对齐官方考试Task，则应把能力作为另一层／另一个视图表达。二者都是可讨论的设计，本轮不擅自确定字段或改变网络结构。

一次定点悬停可以作为一个动作进行联合完成核对，同时为多个能力维度提供证据；一次完整场景也可覆盖多个动作。不能仅按phase序号命名能力，也不能把自拟能力节点直接称为官方考试Task。

已确认的科目一删除高度决定继续有效。它缩小了本场景的覆盖范围，不据此宣称完整覆盖仍包含高度要求的官方任务。科目二仍保留高度、Vertical与垂直速度评价。

本轮结论不是“旧按动作方案全错”或“四能力划分已获官方认证”。下一步应先共同确定item的含义与动作—能力关系，再逐项讨论检查方法。软件、CPT、原始数据均未改动。

## 7. 已确认的项目结构

提出日期为2026-11-02。五类飞行考核项目于2026-11-04确认，检查方法进入第8节讨论。

### 7.1 组织结构与术语

采用：**训练科目／场景 → 具体考核项目（item）→ 检查点**。

- 科目：一次复合训练，如加速减速，或斜飞到点与上下点悬停。
- item：有明确动作目标、完成状态和评价依据的飞行机动。如定点悬停，不再把速度、位置、高度、航向分别直接当作四个考试项目。
- 检查点：描述完成该动作需要满足的控制要求，包括飞行精度和操纵过程。
- phase：输入数据的观察范围，不是官方项目编号。项目与phase可以一对一，也可以一对多，依据动作目标与标准来源建立映射。
- 能力分析：速度、水平定位、垂直控制、航向、操纵质量等可作为检查点标签和报告分析维度。暂不因此增加一套独立能力节点或跨项目综合概率；如需要，后续单独确定证据依赖与量化方法。

每个item继续由检查点表现提供贝叶斯证据，输出该机动中体现的综合技能概率与分数；同时保留规则D/A/U与P/F。它不是只有一个最终位置／速度结果，也不是每项任务只对应一个操纵轴。

### 7.2 权威依据的标注原则

每项记录：官方文件、原项目名称／条款、所在页、支持的具体要求、场景适配及未覆盖部分。

本版使用两种来源性质：

1. **官方有直接动作项目**：如EASA定点悬停。项目可沿用动作名称，但检查范围与数据覆盖仍需说明。
2. **依据官方动作或技能要求进行适配／组合**：如将常规前飞返回悬停适配为30 knots减速后在指定区域水平停止；将垂直控制要求适配为两个空中点之间的升降。名称明确表达本项目动作，不伪称官方存在完全同名的考试Task。

FAA ACS属于考试标准，EASA AMC属于符合性指导，教员指南属于教学参考；三者在来源表中分别标注，不混称为法律强制数字。数值边界、机型操纵规律、D/A/U分档及CPT另行确定，不由“引用了某份标准”自动获得。

### 7.3 科目一：直线加速、保速与定点停止

本版核心飞行项目建议2类。沿用用户任务：phase 1加速并保持30 knots，phase 2受控平滑减速并停在指定区，phase 3确认结束。

| 推荐item | 动作目标与候选检查内容 | 数据范围 | 权威来源 |
|---|---|---|---|
| **1. 直线飞行与速度变换（加速与保速）** | 建立并保持任务速度；保持水平直线航迹和航向；观察速度建立、超调、修正及纵向／横向／偏航操纵的平顺协调。 | phase 1。加速与保速采用不同适用条件，不将加速中正常低于30 knots判为失败。 | EASA AMC2 FCL.235(e) Section 4(a)；EASA教员指南Ex6；FAA-S-ACS-17 AP.II.E.S5/S6作速度与航迹补充参考。 |
| **2. 受控减速与定点停止** | 受控地降低水平运动速度；保持水平路线与航向；到达停止区并连续保持水平停止；观察减速与末端修正操作。 | phase 2，包含末端停止。phase 3只作边界，不因确认而自动通过。 | EASA AMC2 FCL.210 PPL(H) Ex23回到悬停部分及教员指南Ex23；指定位置保持参考FAA-S-ACS-2 CP.IV.A.S6。 |

第1项依据直线飞行与速度变换要求，不因为数据写了phase 1才成立；第2项依据受控返回悬停的机动要求，也不因为写了phase 2就自动等于FAA Quick Stop。

本场景明确排除全部高度、垂直速度和Vertical轴考核。不能因源条款含高度而在组合误差、停稳门限或贝叶斯证据中重新引入。30 knots、约500 m和停止区为项目任务参数，使用地速还是空速仍需按场景定义核对。源训练练习的速度／高度条件不同，本场景属于部分控制要求的适配，不完整复现该官方任务。

第2项不命名为最大性能快速停止／Quick Stop，不要求拉满杆或最短时间制动。到点后的水平停稳是本次机动完成状态；不额外增加定点悬停保持项目，也不增加科目二那样的垂直保持考核。

### 7.4 科目二：低速移位、垂直转移与定点悬停

本版核心飞行项目建议3类。同一类项目可以有多次动作实例，分别报告，再按该item汇总。

| 推荐item | 动作目标与候选检查内容 | 数据范围 | 权威来源 |
|---|---|---|---|
| **1. 低速移位与到点悬停** | 从起点受控移向下方目标；保持规定路线，完成到点减速并建立悬停；观察操纵平顺与协调。完整到点状态包括位置、高度、运动和航向。 | phase 1，包含到点捕获／悬停建立；随后phase 2负责持续保持。若上游phase边界划分不同，需要明确证据归属，不重复计同一帧。 | FAA-S-ACS-2 CP.IV.B.S6的悬停移位、CP.IV.C.S6的点到点飞行；到点状态参考CP.IV.A.S5/S6/S8；EASA教员指南Ex11b。 |
| **2. 定点悬停** | 在当前上／下目标点同时保持水平位置、高度和航向，抑制水平／垂直漂移；观察适度修正与平顺协调操纵。 | phase 2、4、6、8，四次独立保持，保留每次结果及时间记录。 | EASA AMC2 FCL.235(e) Section 2(c)定点悬停；FAA-S-ACS-2 CP.IV.A.S4/S5/S6/S8；EASA教员指南Ex11a，必要时参考Ex18a的OGE背景。 |
| **3. 垂直升降与悬停建立** | 沿垂直方向到下一目标高度，保持水平位置与航向；控制目标捕获、超调及垂直停稳；观察四轴操纵配合和修正。 | phase 3、5、7，共三次转移；悬停建立后，持续保持由下一次定点悬停实例评价。 | FAA-S-ACS-2 CP.IV.A.S4的无漂移升降、S5/S6/S8的高度／位置／航向要求；EASA教员指南Ex12的起降至／离悬停原理作教学参考。 |

“低速移位与到点悬停”是悬停滑行／点到点机动与目标捕获要求的组合适配，暂不把整个phase 1直接命名成完整FAA Hover Taxi、Air Taxi或Normal Approach to a Hover；是否符合这些具体机动的条件需核对速度、高度、路线及飞行方式。

“垂直升降与悬停建立”是对官方垂直控制要求的适配。原CP.IV.A包含地面起降，本场景是两个空中点之间转移，不能把两者描述成完全相同的正式考试任务。没有规定转移速度或耗时前，不强加唯一高度—时间曲线，也不逐帧将“尚未到目标高度”当差表现。

定点悬停保持完整保留高度，水平定位、高度、航向在同一动作中联合满足。光点若沿用，可作辅助证据／展示；不把“激光命中”单列成官方飞行考试项目，也不以其代替完整运动状态。

### 7.5 每个item的共同评价要求

仿照成熟考核，对每项机动同时检查：

| 评价方面 | 需要回答的问题 |
|---|---|
| 动作完成 | 是否确实完成指定机动并达到规定末端／保持状态？ |
| 飞行精度 | 速度、路线、位置、航向及本任务适用的高度是否满足要求？ |
| 操纵质量 | 输入是否适合动作目标、平顺协调，并产生合理响应？ |
| 偏差修正 | 偏差发生后，修正是否及时、有效，是否反复加剧偏差？ |

其中操纵平顺性、协调性和修正质量放入各项目的检查点，不再仅凭一般原则将其并列为一个新的独立考试动作。共同原则参考EASA AMC2 FCL.235(c)(2)/(5)及相应机动的教学要求。具体检查点可以合并相关要求，数量不在本轮锁定。

原始操纵输入必须参与方法设计。不得仅根据“操作次数少、杆量小、低变化率”认定熟练；状态结果可解释操纵，但同一偏差不能作为独立证据重复计入。没有眼动／提示／教员干预等证据时，不宣称已检验观察行为、心理状态或帮助依赖。

### 8.1 数据与判定约定

| 内容 | 数据与用法 |

| 直线与航向 | 以场景配置的起点和目标方向定义沿线进度及有符号横向偏差。已核对的科目一起始参考为 `(0, 0)`、机头270°，前飞沿世界−X。航向误差用最短角差 `wrap180(psi − psi_ref)`。 |

| 操纵输入 | 科目一读 `Pilot Lon/Lat/Yaw`，科目二还读 `Pilot Heave`。以模式、操纵轴、动作目的和可见响应解释输入。控制律语义及操纵阈值需用机型配置和专家标注确定。 |

### 8.2 科目一①　直线飞行与速度变换

| 检查 | 计算及判定办法 |
|---|---|
| 速度建立与保持 | 使用phase 1。加速段记录首次持续进入目标速度带的时刻、最大正超调和回落过程。建议以连续满足配置的捕获带和最短时间作为建立条件，取得该证据后进入保速评价。保速阶段计算 `v_task − 30 kt`，保留其峰值、最长连续超差、恢复时长。首次有效建立后，其余速度下跌或再次超调归在同一次保速记录中。正常起速期间，低于目标是预期状态。阶段完整但最终未达到配置的建立与保持要求时，记完成条件U。若任务另有到速时限，单独配置。 |

### 8.3 科目一②　受控减速与定点停止

| 检查 | 计算及判定办法 |
|---|---|
| 主要减速过程 | 从phase 2开始，结合 `Pilot Lon` 的减速输入和纵向减速度变化评价平顺性，按8.3.3处理。初次停下后重新移动以进入目标区，归末端位置调整。 |
| 停止点预判与一次到位（D-010，取代原“末端位置调整”） | 检查首次停止点位置、越过与停短、首停后的再移动及其操纵杆修正，以及从开始减速到停稳的用时，按8.3.4处理。首停后为进入停止区的移动仍然允许。 |

判定示例。飞机第一次在区外短停，随后低速后移进入区域，并在末端连续满足位置、速度与适用航向条件，则通过完成检查。飞机曾在区内停稳，随后移出且到任务结束仍未回到区内，则完成检查为U。反复调整按过程边界判断，已经触发的过程U会保留。

#### 8.3.1 检查点一　最终停点位置精度与容差试算

**已确认的检查方法。** 当前直线场景以phase 1起点 `(0, 0)` 为参考，前飞为世界−X，500 m处的候选中心为 `(-500, 0) m`。最终水平位置的带符号误差为 `ΔX = X_end + 500` 和 `ΔY = Y_end`。`ΔX > 0` 表示欠距，`ΔX < 0` 表示越过参考中心。报告同时显示 `hypot(ΔX, ΔY)`，判档逐轴使用矩形范围，两轴同时满足才进入该档。

位置取最后一次调整后的末端位置。历史CSV的分布试算使用phase 2末帧。正式检查将末帧误差与连续停稳证据配合使用。终止窗口内还需连续满足停止区及低水平地速要求。初次停点偏差和修正情况归各自的过程检查。

| 位置档位 | 纵向误差边界 | 横向误差边界 | 科目一65次停点试算 |
|---|---|---|---:|
| D | `abs(ΔX) ≤ 5 m` | `abs(ΔY) ≤ 2 m` | 12次（18.5%） |
| A | `abs(ΔX) ≤ 15 m` | `abs(ΔY) ≤ 5 m`，且两轴组合未达到D | 41次（63.1%） |
| U | 任一轴越出A区 | 任一轴越出A区 | 12次（18.5%） |

D区是 `X∈[-505,-495] m`、`Y∈[-2,2] m`。A外区是 `X∈[-515,-485] m`、`Y∈[-5,5] m`。边界计入对应区域。此处81.5%是落在A外区内的停点覆盖率，包含D。更严格的A备选 `X±10 m、Y±5 m` 覆盖47/65（72.3%）。

**数据口径。** `data/Mai_task1_accelerate_decelerate` 共66份CSV，按完整内容去重后为65份。`|ΔX|` 的中位数为6.35 m，第90百分位为12.84 m，第95百分位为15.43 m。`|ΔY|` 的对应值为1.63 m、5.21 m、5.44 m。D档用于区分较准停点，A档按分布取整到15 m和5 m，中心以任务定义为准。停点样本的分布是边界取值的依据。

**条款依据。** FAA-S-ACS-2 的 CP.V.D.S7（印刷26页、PDF31页）要求正常进近在指定到达点建立稳定悬停，给出±2 ft（约0.61 m）的精度。CP.IV.A.S6（印刷18页、PDF23页）也使用指定点位置保持。EASA教员指南Ex13（印刷133页、PDF141页）强调在选定点建立悬停，Ex23（印刷182–183页、PDF190–191页）给出减速接近零后建立稳定悬停的教学过程。上述要求支持把指定点、位置精度和稳定完成作为检查内容。科目一的X/Y矩形、500 m参考中心及D/A边界是仿真场景适配，FAA的英尺数值属于对应的正式悬停任务。[FAA CP.V.D.S7](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf#page=31) [EASA教员指南Issue 4.0](https://www.easa.europa.eu/en/easa-together4safety-helicopter-flight-instructor-guide-issue-40)

#### 8.3.2 检查点二　减速过程飞行精度（待确认）

主减速段逐帧检查飞机有没有沿指定的直线走，以及机头有没有维持任务规定的航向。横向航迹与机头航向各反映一种误差。飞机可以保持机头270°而侧滑出走廊，也可以保持在走廊内而机头偏转。

| 观测量 | 用实采数据计算 | D试算边界 | A外边界试算 |
|---|---|---:|---:|
| 水平横向航迹误差 | `e_y = Ye − 0 m`。固定参考线从 `(0, 0)` 指向 `(-500, 0)`，每帧取到该线的有符号横向距离。 | `abs(e_y) ≤ 2 m` | `abs(e_y) ≤ 5 m` |
| 机头航向误差 | `e_ψ = wrap180(psi − 270°)`。用机头航向 `psi deg`，按最短角差计算。 | `abs(e_ψ) ≤ 5°`，采用FAA商照航向容差 | `abs(e_ψ) ≤ 10°`，采用FAA私照航向容差 |

两项误差均沿用场景参考。phase 2入口已有的误差标为“进入减速时已偏离”，随后显示是否继续偏离或纠正。X用于显示沿线进度和识别停点，最终纵向位置由8.3.1评价。主减速段无需指定每一秒应该飞到哪个X。主减速段的减速度变化按8.3.3评价。低速修正期间继续保存完整轨迹，按8.3的末端调整范围、速度和适用航向另行评价。

**时间窗口。** 正式计算优先使用输入中标明的主减速段边界。现有CSV的phase 2将主减速和后续调整记在一起，本次回放从phase 2首帧起，到首次持续至少0.5 s的低速段起点止。低速条件暂用 `hypot(V_ex, V_ey) ≤ 0.5 m/s`，时长按 `Simulation time` 计算。这个条件用于划分回放过程，连续停稳按最终调整后的独立窗口检查。若旧记录未找到低速段，则展示已观测的过程并标记结束边界未识别，由最终完成检查判断有完整记录的未停稳情况。

**判档与复盘。** 每帧两项都在D区为D，都在A外边界内且至少一项超出D为A，任一项越过A外边界为U。主减速段先用严格边界回放，按全程最差帧统计档位。保存两条原始误差曲线、各自峰值、越界起止、最长连续超差与恢复时刻。正式判档如需容许短时超差，应预先定义最大幅度、持续时间和恢复条件，经专家复核后启用。帧级原始越界仍保留。两条曲线可分别查看，整项模型中同一帧的综合档位只计一次。

#### 8.3.3 检查点三　减速平顺性（输入与响应已确认，合并判据待讨论）

**评估意图。** 检查从前飞降至首次停下的过程中，飞行员能否建立并大致保持适当的纵向输入，以及飞机的纵向减速度是否突然变化。首次停下后为进区而重新前移，与后移、侧移一样归末端位置调整。飞机响应与中段杆位变化范围分别使用下文已确认的分档，保留过程证据；最终合并判据待讨论。

#### 8.3.4 检查点四　停止点预判与一次到位（D-010）

**评估意图。** 熟练的飞行员建立减速输入并保持，接近停点时回杆，使飞机一次停稳在指定区域。对接近速度和停止点判断不准时，需要停下后再挪动；挪动越多，挪动中的无效修正和反复修正越多，说明预判和操纵越不熟练。首停后的移动允许（D-003），不单独判任务失败。

**操纵杆修正的划分。**

1. 杆输入：杆量绝对值 >5 持续 ≥0.05 s 为一次输入，记方向、保持时长、峰值和修正杆量 `∫|u|dt`。

| 类别 | 判定 | 评价 |

| 反复修正 | 输入前飞机正以 >0.2 m/s 反向运动，输入使速度越过0并以 >0.2 m/s 朝输入方向运动 | 扣分 |

### 8.7 操纵过程、证据归属与分数

1. 从已确认的通道标度和时间戳提取有效动作，包括幅度、速率、反向间隔。预先配置死区、最小动作幅度及响应观察窗。不同阶段和控制模式分别核对。
2. 将动作前的偏差、动作本身及随后误差变化连成一条记录。关注是否改善偏差、是否需要反向纠正、是否产生显著再超调。对末端移位，直接看距离停止区是否缩小，并结合移动速度与范围解释。
3. 第一版可直接输出动作与响应的可复核诊断。独立的操纵D/A/U需要确认控制律和响应窗口，并由专家标注校准平顺和过度修正的边界。飞行精度使用对应的场景边界单独判定。
4. 时序更新只提交当时已成熟的证据。完成型判断在相应窗口形成后提交一次。把同一状态用于解释操纵时，重复部分只贡献一次概率证据。重叠窗口、100 Hz相邻帧与重复动作的依赖在网络对接时单独处理。
5. 报告保留逐次动作、项目D/A/U、P/F与贝叶斯概率／分数。重复项目按预先确定的必做实例汇总。是否达标由完成条件与规则结果给出，概率分数用于说明所观察到的技能表现。

本稿使用实采数据核查指标可计算性及判定陷阱。参数表仍需填写速度信号、目标区几何、上下悬停点与路线、航向、误差带、持续时间、末端调整范围／速度和操纵标定。样本描述值用于复核方法。资料参见[实采数据字段与阶段解析](../../../../data/真实飞行数据解析表_2026-10-11.md)及[科目一实采检查讨论稿](../reviews/2026-10-14-scn001-real-data-evaluation-proposal.md)。

## 9. 贝叶斯网络优化方案（2026-11-12，待确认）

范围：替换现行 `sequential_bayes_compensation_v1` 的证据计算方式。网络结构（item三档能力 → 检查点CPT）、先验、状态分值0/50/100、规则D/A/U与P/F均不变，适用于第7节五类item。本节回应8.7第4点关于相邻帧、重复动作与证据归属的问题。

### 9.1 现行方法的问题

现行方法每个有效帧都把CPT似然完整乘一次，再按α=0.2向本帧item档位补偿。用现行算法逐帧重放演示输入，结果与软件报告的分数完全一致（误差0）。

| 问题 | 数据 |
|---|---|
| 分数只反映最后几帧 | 6份合成演示的12个飞行item中，不合格案例（含10%～31% U帧）的4个item末帧均为100分，勉强合格多为50分，熟练均为100分。65次实采中，只保留减速过程航迹与航向检查点时，主减速段最后一帧为D的34趟全部≥99分，其中航迹U时间占比最高34%。 |
| 判断几乎不保留历史 | 100 Hz下U段结束、恢复D后，0.04 s内回到90分以上。 |
| 随采样率变化 | 只保留航迹与航向检查点时，同一记录由100 Hz降为10 Hz，末帧分数最多相差24.5分；三个检查点一起时最多相差4.7分。 |
| 结果型检查无合适入口 | 最终停点位置、`B`、`H`、停稳完成每次动作只有一个结果。逐帧方法中它们只占一帧，权重无法与持续数千帧的检查相比。 |
| 重复动作未规定汇总 | 定点悬停4次、垂直升降3次的实例如何进入同一item，现行方法没有规则。 |

原因：100 Hz下每帧都作为一份独立证据，证据量随帧数无限累积；为防止概率锁死又每帧补偿20%，结果只记住最近约5帧。

### 9.2 优化后的计算：按动作实例归一的序贯贝叶斯

1. **证据总量按动作实例固定。** 每完成一个必做动作实例，item共获得κ份证据，按检查点权重 `w_k` 分配（默认等分，`Σw_k = 1`）。帧数、采样率和动作时长都不改变证据总量。
2. **持续型检查点**（逐帧判档，如减速过程航迹与航向、保速）：该实例中每个适用帧贡献 `ω = κ·w_k / N_k`，`N_k` 为该检查点在本实例的适用帧数。整段贡献等于各档帧数占比乘以对应的CPT对数似然。
3. **结果型检查点**（每次动作判一次档，如最终停点位置、减速平顺性、停稳完成）：在结果形成的那一帧一次贡献 `ω = κ·w_k`。
4. **一个检查点只计一份证据。** 检查点内的多个观测量先按该检查点的规则合并成一个档位（逐帧取最差档，或 `B` 与 `H` 的合并规则），再进入网络。同一飞行员动作的输入与响应不重复计入。
5. **逐帧更新：** `log p_t(s) = log p_{t−1}(s) + Σ_k ω_{k,t} · log θ_k(s, g_{k,t})`，再归一化。先验只在开始时使用一次。
6. **重复实例：** 同一item的多个实例按时间顺序继续更新，每个实例分得 `κ/I`（`I` 为该item的必做实例数）。报告同时给出每个实例单独计算的结果（先验加该实例的κ份证据），便于比较四次悬停或三次升降。
7. **输出：** 分数 `= Σ_s p(s)·v(s)`。过程曲线为截至每帧的累计结果，终点就是item最终结果。报告列出各检查点的档位占比及其对三个状态的对数似然贡献，说明分数由哪些检查点推高或拉低。
8. 删除每帧补偿α。缺测、数据不完整、必需阶段或实例缺失时不给最终概率，规则同现行。

整段等价式：`log P(S=s | 全部证据) = log π(s) + κ · Σ_i (1/I) · Σ_k w_k · Σ_g f_{i,k,g} · log θ_k(s,g)`，`f_{i,k,g}` 为实例 `i` 中检查点 `k` 判为 `g` 的占比（结果型检查点即该次档位）。

性质：最终结果与采样率、动作时长和帧顺序无关；增加检查点不增加证据总量；D推高、A拉向中档、U压低；证据总量有上限，概率不会锁死在顶点，相反证据随时能改变判断，满足2026-09-23提出的双向修正要求。

| 检查点二　减速过程飞行精度 | Ground Track and Heading Control（Lateral Track Deviation、Heading Deviation） |
| 检查点三　减速平顺性 | Deceleration Smoothness（`B` Deceleration Rate Change、`H` Longitudinal Control Input Spread、`J` Short-Term Longitudinal Control Change） |
| 检查点四　停止点预判与一次到位 | Single-Maneuver Transition to Hover（Initial Hover Position Accuracy、Overshoot/Undershoot Tolerance、Post-Stop Repositioning、Repositioning Control Quality、Time to Stabilized Hover） |
| 最终入区与停稳 | Stabilized Hover Completion |

### 10.4 通用用语

- 评价方面：Maneuver Completion、Flight Path Accuracy、Control Smoothness、Deviation Correction，对应ICAO Doc 9868 OB 4.1 "accuracy and smoothness" 与OB 4.2 "detects deviations … takes appropriate action"。
- 档位：Desired / Adequate / Unacceptable，采用ADS-33 §3.11的 "desired and adequate performance"，取代现软件与D-092中的Acceptable；P/F为Pass / Fail。
