# 贝叶斯离线实验独立复核

复核日期：2026-09-15。对象：`tools/Audit-SceneBayesianParameters.py`、当前运行时 `demo_quantification.py`、本目录 `audit.json` / 5份CSV / `SUMMARY_CN.md`，以及当前生成器重建的两场景六份输入。复核未修改运行时算法、CPT或默认参数。

**结论：数值实验及主要建议得到真实运行支持。保留 current / κ=3 作为当前可追踪演示基线是合理的；本实验不足以证明某候选更符合真实飞行员技能。** 复核发现并已通知主任务修正一处理论表述：“κ越大后验一定更集中”不成立；当前 SUMMARY 已改为提高证据相对先验权重，不保证更集中或更敏感。

## 1. 独立重算与产物一致性

为避免仅重复调用被审查函数，独立核验使用直接幂乘形式：

\[
u_s=\pi_s\prod_c\prod_g C_{c,s,g}^{\kappa w_cq_{c,g}},\qquad
p_s=u_s/\sum_r u_r,\qquad S=\sum_s p_sv_s.
\]

被审查实现使用 log-sum-exp 路径；两条计算路径不同，但数学定义相同。测试参数范围内直接幂乘未产生下溢。

| 核验 | 结果 |
|---|---|
| 审查脚本、推断实现、生成器的来源SHA | 最终核验3/3与当前audit记录一致，包含主任务修正SUMMARY措辞后的再生成版本。 |
| 180组模型 × 7个锚点 | 1,260组独立重算，最大绝对误差 `5.6843418861e-14`。 |
| 全部模型的比例网格单调性 | 75,600次相邻改善比较，违规数量逐模型与audit一致。 |
| 五组有序候选 | 150组参数、63,000次比较，违规0。 |
| 刻意不良CPT | 30/30组参数有违规；当前尺度下单一案例最大降分约8.19684。 |
| 代表性过程CSV | 72,000个过程点独立重算，最大分数误差 `2.2737367544e-13`。 |
| 当前生成器的输入指纹 | 六份输入重新生成，6/6与audit记录的规范JSON指纹一致。 |
| 真实案例全部候选 | 2,700行独立重算；最大分数误差 `1.0658141036e-13`，最大后验误差 `9.9920072216e-16`。 |
| 当前参数与真实evaluate | 15个item案例最大分数差 `2.8421709430e-14`；P/F一致。 |
| CSV行数 | model_summary 180；trajectory_summary 720；binary_gate_comparison 1,260；representative_trajectories 72,000；actual_case_comparison 2,700。 |

因此本报告中的主要数值不是仅依据图形外观或手填结论。小数舍入应注意：SUMMARY 的“全U=0.00”是两位小数展示；当前参数实际为 `0.0014568533225910488` 分，后验也没有被硬截断为纯Low。

## 2. 单调性结论成立，但范围要说清楚

在固定先验、固定正κ、固定非负检查点权重和递增状态分值下，把某检查点固定总量中的一部分证据从 U 改为 A，后验各状态被乘以 `C(s,A)/C(s,U)` 的相应正幂。如果这个倍率随 Low → Middle → High 不减，后验向高状态移动，分数不会下降。A 改为 D 同理。

脚本的 `likelihood_order_certificate` 正是检验相邻状态、相邻观察等级的这一条件。相邻关系传递后覆盖其余状态对。因此前五个CPT不仅在5%网格上没失败，也具备上述固定模型下的充分条件；这不等于已证明现实效度。

刻意反例有用且不是代码错误：在 `counterexample / κ=3 / uniform / [0,50,100]` 中，从 D20% / A0% / U80% 改善为 D20% / A5% / U75%，分数反由 `57.53587249` 降至 `49.33903378`。说明“行和为1”和“High的D概率较高”不足以保证改善会加分。

上述结论比较的是**同一个模型、同一组检查点、固定总证据中的等级改善**。新增检查点后重新分配权重、改CPT或改状态分值属于改变模型，不能引用这个定理保证分数与修改前可直接比较。

## 3. κ与累计平滑：实验解释正确

当前CPT、均匀先验、[0,50,100]，60秒序列中只出现1秒U：

| κ | 第10秒开始U时的最大下降 | 第50秒开始U时的最大下降 | 两种顺序共同最终分 |
|---:|---:|---:|---:|
| 1 | 8.652875 | 1.653465 | 78.231483 |
| 2 | 8.108917 | 1.285663 | 91.360795 |
| 3 | 5.584606 | 0.753566 | 96.467779 |
| 6 | 1.288705 | 0.101414 | 99.744390 |
| 12 | 0.043387 | 0.000914 | 99.998684 |

这直接支持“κ加大可能更饱和、对短暂失误反而更不敏感”，不支持“κ越大曲线一定波动更明显”。

非均匀先验时，增加κ也不保证熵单调下降。已有模型 `current / mid_heavy / all_D` 的κ从1到2，后验熵由 `0.6618822786` 增至 `0.7191946596`。因为证据与偏重Middle的先验竞争，后验可以先变分散，再在更大κ下偏向High。主任务已据此收窄SUMMARY措辞。

对于累计比例，新增m帧对既有n帧比例的改变是

\[
q_{n+m}-q_n=\frac{m}{n+m}(q_{\text{new}}-q_n).
\]

所以较晚的相同短失误对累计比例影响更小。用户已选择“截至当前时刻的累计分数”，这种后段平滑是定义的结果。要展示即时失误应结合原始值、D/A/U过程及局部曲线，不能承诺只调CPT便同时获得任意强即时响应和原有累计语义。

本次同占比100帧/10,000帧、相同时序总数重排的最终分差均为0。同档抖动探针原始值最大差约0.8，D/A/U完全相同，分数差也为0。该结果符合输入只使用等级比例的数学事实，不是模型遗漏了本来接收的连续幅值信息。

## 4. 常D的禁止事件Gate既可能抬分，也可能压低高分

对两个相同连续检查点，增加一个常D的二元检查点，并将三者重新等权，当前模型得到：

| 连续表现 | 两个连续检查点的分数 | 加常D Gate并三者等权 | 差值 |
|---|---:|---:|---:|
| 全D | 97.096879 | 93.189420 | -3.907458 |
| 全A | 47.251992 | 48.563601 | +1.311608 |
| D90/A9/U1 | 93.490483 | 88.876682 | -4.613802 |
| D70/A20/U10 | 70.483136 | 71.946185 | +1.463049 |

原因不是“做对了反而被罚”的单调性错误，而是**换了权重和证据语义**：连续D对High/Middle的似然比约2.5714；二元Gate的D只有约1.0194。重新等权后，原本用于区分熟练程度的证据权重减少；Gate更接近低门槛完成性。

实际快速减速item也同时出现两个方向：熟练案例含Gate约92.08分、移除后约96.29；勉强合格含Gate约51.86、移除后约48.92；局部U案例含Gate约58.79、移除后约48.99。它支持“单独讨论Gate是否进入连续能力分数”，不能简单声称Gate总会虚增分数。

这里的Gate移除试验是结构/权重敏感性分析，**不是已经验证了移除后更真实**。建议暂不直接修改现行参数；先由用户决定该item分数要表示“连续操纵质量”还是还包括“规定动作/限制遵守”，然后再确定证据模型。P/F的禁止事件约束可独立保留。

## 5. 为什么本轮应保留current而不宣布某候选更优

1. 前五个CPT都通过方向性要求，却给同一D70/A20/U10约58–75分；单调不等于数值已校准。current不是唯一有效模型，也不是实验挑出的真实性最优模型。
2. 三种合成案例是人为构造的行为差异。其“不合格”是出现U的规则标签，不是对整段平均操纵质量的独立专家量表。不能把合成Fail必须最低分当作优化目标。
3. 改中间状态分值50→65，对任意固定后验恰好加 `15×P(Middle)`，不改变后验或识别信息。CPT、κ、先验和状态分值应分开解释。
4. 同一CPT复制到多个item，方便原型保持统一，但不证明五个飞行能力已分别测量、也不解决相关检查点重复计权。应先修正标准审查发现的观测缺口，再考虑标定。
5. `gentler κ=2/3` 和 `current κ=2` 可以进入专家对照清单，依据是分数响应形状更温和这一工程观察；**不是当前数据已经证明这几组更适合真实飞行员**。

建议后续以相同的场景条件、明确Low/Middle/High含义、独立教员判断和留出的飞行记录进行校准验证。标定数据要与调参展示集分开；不凭空规定所需样本数。

## 6. 方法依据与其不能证明的事情

[Bissiri、Holmes与Walker（2016），原始论文](https://boa.unimib.it/retrieve/handle/10281/105779/173282/1-General_Bayes.pdf)给出了用损失函数进行广义贝叶斯更新的框架。它支持把“先验×指数化损失”作为一种明确的建模方式，**不提供飞行员D/A/U的CPT、κ=3或状态分值**。

当前实现用归一化比例、固定总强度对每个前缀从原先验重算。它是有意避免帧数无限放大证据的项目模型，不能冒称为每帧条件独立、用前一后验直接递推的经典贝叶斯网络，也不是动态贝叶斯网络。论文的逐次更新一致性不能未经说明直接当作本项按前缀重新归一化方案的实证证明。

[SHELF官方框架](https://shelf.sites.sheffield.ac.uk/)与[官方工具说明](https://shelf.sites.sheffield.ac.uk/software)支持组织专家提出概率判断，包含总和为1的比例分布获取工具。可以借鉴这一过程讨论三态CPT及不确定性；它不是现成飞行员参数库。本轮没有进行正式专家引出或实飞标定。

FAA/EASA/CAA的操纵容差只帮助定义本场景什么行为落D/A/U，不能由容差直接推出 `P(D|High)` 等频率。本次报告在这点上保持了正确边界。

## 7. 最终判定

- **数值与复现：通过。** 核心CSV/JSON、真实生成案例及报告解释一致。
- **单调性：current及其余四个有序候选通过；刻意反例按预期失败。**
- **κ解释：发现一处过度概括，主任务已修正；“更大不等于更敏感”得到实测支持。**
- **参数上线建议：保持当前基线。** 其他候选作为待专家/数据验证的备选，不将本次合成测试包装成标定结论。
- **修改边界：本独立审查仅新增本REVIEW文件，未改变任何运行时模型参数。**
