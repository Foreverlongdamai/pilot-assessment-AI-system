# 两场景全量飞行检查点与标准映射审查

查证日期：2026-09-15。范围：SCN-001 / SCN-002 的 6 个 item、20 个检查点，以及导师演示配置的 D/A 数值。本文是独立审查结果与后续建议；除已获用户授权的空中滑行速度曲线修订外，**本审查没有修改其他检查点、阈值或 P/F 规则**。贝叶斯参数实验由同轮单独报告负责；本文说明进入模型的证据是否足以代表所声称的技能。

采用飞行教员进行任务讲评时的关注顺序：任务是否实际完成 → 轨迹和速度是否受控 → 是否平顺协调 → 是否符合限制。这里是依据公开标准进行的工程审查，不是持证教员签署的鉴定。

## 结论与优先级

现有设计可以称为“参考官方操纵要求、经过场景适配的训练评估原型”。**不能称为完整实现 FAA / EASA / CAA 技能考试**。保留 item 与检查点的结构是合理的；目前最值得先补的是观测内容的缺口，而不是先调整 CPT 让结果看起来更合理。

| 优先级 | 问题 | 建议 |
|---|---|---|
| 1 | 急停没有任何速度证据，不能独立确认减速或真正停止 | 在现有 item 内补减速过程速度与末端近零地速；固定终点精度保留为场景要求。暂不声称评估“最大性能减速”。 |
| 1 | 垂直升降 item 没有高度或垂直速度 | 补升降过程高度/方向证据，或把名称收窄为“升降期间水平与航向控制”；推荐前者，但曲线形式和阈值须与用户确定。 |
| 1 | 进近路线距离不检验沿路线前进和路线完成 | 保留逐帧空间距离，再补进度/终点覆盖；不必因此恢复之前被用户删除的逐秒进近速度剖面。 |
| 数据建议 | 部分演示阶段观测过短/过少，首末跨度也不代表完整过程 | 按用户最新澄清，停止阶段应提供很多帧；本轮优先修正演示输入覆盖，不因此强制新增系统采样规则。 |
| 2 | 激光与高度、位置、航向存在物理耦合，却作为额外等权能力证据 | 保留激光可视化与独立反馈；量化时审查重复计权，不能把增加一个相关检查点当作新增独立技能证据。 |
| 2 | 到点与持续悬停的同类量使用不同精度，但界面容易让人误认为相同标准 | 明确标注“终点捕获精度”与“持续悬停容差”的场景差异，或者后续统一。不能仅为演示分数调阈值。 |
| 2 | 任一 U 即 Fail 与官方考官整体判断不是同一逻辑 | 保留用户已选规则，并标为“本项目训练规则”；继续同时显示 U 记录和综合分数。 |

## 1. 原文来源与适用边界

### FAA

- 主锚点：[FAA-S-ACS-2 Commercial Pilot for Powered-Lift Category](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf)，在线 PDF 封面 November 2023，75 页。章节代码采用 CP。它包含知识、风险管理、技能，不只有轨迹容差。
- 补充：[FAA-S-ACS-17 Airline Transport Pilot and Type Rating for Powered-Lift Category](https://www.faa.gov/training_testing/testing/acs/atp_pl_acs_17.pdf)，章节代码 AP。其 AP.II.E.S5 明确指定空速、滑行高度及航迹要求，属于不同证照/型别考试层级；**不能把它的空速数值写成 ACS-2 的原规定**。
- [FAA powered-lift FAQ](https://www.faa.gov/air-taxis/FAQ)说明该类别兼有垂直飞行及翼面巡航特征。eVTOL 是动力/构型描述，不能仅凭这个名称断定每种模拟飞行器均完全适用 powered-lift 的全部任务。

本次使用的条款索引：CP.II.E.S1–S6（检查单/性能/构型，PDF18–19）；CP.IV.A.S4–S8（升降、定点/高度/航向，PDF23）；CP.IV.C.S3–S7（空中滑行，PDF26）；CP.V.D.S5–S7（正常进近至悬停，PDF31）；CP.VI.A.S3–S6（快速减速，PDF37）。这些条款分别支持任务内容；没有定义本软件的 D/A/U、CPT 或每秒参考曲线。

### EASA 与 UK CAA

- [EASA Flight Examiner Manual Module 3.3 CPL(H), V2023.1](https://www.easa.europa.eu/en/downloads/138658/en)：PDF10 的 Section 2(b)/(c)、PDF20 的 Section 2 Skill，支持滑行与定点悬停的操纵维度；PDF17 的 Section 7 同时要求平顺、准确、可控，容差需结合条件。**它是直升机 CPL 考试，不是通用 eVTOL 合格证标准。**
- 更直接的 VCA 适配依据是 [ED Decision 2025/011/R 附件，PDF2](https://www.easa.europa.eu/en/downloads/142208/en#page=2)：AMC1 Article 4f(2)/(3) 让 VCA 型别课程沿用直升机课程设计原则，同时按具体 VCA 与 OSD 选择、修改及补充知识内容；GM1 Article 4f(3)(a)(i) 引用 Part-FCL Appendix 9 Section A。**这支持有说明的适配，不能据此照搬 CPL(H) 全部数值。**
- [UK CAA Standards Document 03(H)](https://www.caa.co.uk/publication/download/12966)：下载链接的搜索元信息写 V5，但 PDF 正文是 **V6 / May 2021**。本审查以正文为准，不把它表述为最新发布的 eVTOL 专用文件。PDF18 的 Section 2(a–c) 含悬停维度；PDF19 的 2(g) 描述 Quickstops；PDF14 §3.1.2–3.1.3 说明容差越界与考试失败并非机械一一对应，平顺协调、天气与操纵特性也影响判断。

CAA 2(g) 的顺风快停包含转回迎风的直升机技术。因此当前固定航向的直线场景应明确为无风/适当迎风条件的简化练习，不应声称覆盖了所有风向快停。

## 2. 20 个检查点逐项审查

“合理”指可作为所述训练维度的观测，不等于覆盖整项官方考试。“项目”指现行额外要求，没有查到对应通用官方数值。

| item / 检查点 | 当前实际计算内容 | 官方锚点 / 适配判断 | 应改进的内容 |
|---|---|---|---|
| 起飞前 / A-S1-06-01 电池与供电 | `battery_check_completed` 布尔值 | CP.II.E；项目电推进条目，合理 | 只代表检查完成，不证明电池状态合格或故障处置正确。 |
| 起飞前 / -02 推进与功率 | `propulsion_check_completed` | CP.II.E.S1/S6；合理的完成性简化 | 应在输入说明中约定检查计划需要包含可用性能判断；不能从 true 推出实际余量足够。 |
| 起飞前 / -03 飞控与起飞构型 | `flight_configuration_check_completed` | CP.II.E.S3/S6；合理 | 型号未确定时保持通用字段，不虚构统一开关序列。 |
| 起飞前 / -04 飞行仪表 | `flight_instruments_check_completed` | 项目对检查单的拆分；ACS-17 AP.II.F.S4 可补充参考 | 不是眼动注视，也不证明理解仪表；该简化已由用户选择。 |
| 起飞前 / -05 告警与系统 | `alerts_check_completed` | CP.II.E；合理的完成性简化 | 正确发现故障并处理可以完成检查；不要把完成性等同“所有系统无故障”。 |
| 起飞前 / -06 导航与任务 | `departure_check_completed` | 项目拆分；ACS-17 AP.II.F.S4/S5 可补充参考 | 不把这一个 true 宣称为已完整评估航前计划、通信与风险管理。 |
| 正常进近 / A-S2-23-01 航迹 | 各帧 XYZ 到整条有限折线的最近三维距离 | CP.V.D.S5 的部分空间映射，合理 | 不含时间进度、沿向、完整到访、速度与稳定进近；单凭此点不能声称覆盖 S6。 |
| 正常进近 / -03 到点悬停 | XYZ、vx/vy/vz、heading 各自判档，同帧取最差 | CP.V.D.S7 的合理工程代理 | 对持续时间/连续观测需要完整性约定；近零速度是补充，不能替代位置。 |

| 空中滑行 / -02 高度 | 实际高度减指定高度 | CP.IV.C.S5；合理 | 6 m 目标是场景设定，AGL 与坐标高度须有明确约定。 |
| 空中滑行 / -03 航迹和航向 | 固定直线的横向位置 + 实际航向最短角差 | CP.IV.C.S6、AP.II.E.S5；部分映射合理 | 地面航迹与机头航向分开保留；有侧风时参考航向不能默认等于路线方位。 |
| 急停 / A-S2-30-02 停止位置 | `stop` 帧 XYZ 与终点 | 项目终点精度要求，可保留 | **坐标到点不等于速度为零**；没有末端速度不能验证“停止”。 |
| 急停 / -03 过程控制 | 全减速段及 stop 帧高度、heading、横向位置 | CP.VI.A.S3 及相关控制要求的部分映射 | **没有速度/减速量**；不能判断减速迟缓、途中再次加速或最大性能。 |
| 急停 / -04 限制与禁止接触 | 每帧事件数 0 / 非0 | 项目外部事件结果门控，合理 | 列清上游究竟认定了哪些事件；未定义的限制不能被一个0自动证明满足。 |
| 悬停 / A-S2-02-01 水平位置 | X/Y 与 vx/vy 分别比较，同帧最差 | CP.IV.A.S6、EASA/CAA定点悬停；合理 | 逐轴矩形与圆形容差不同；速度阈值为项目值。 |

| 悬停 / -02 航向 | 实际 heading 与目标最短角差 | CP.IV.A.S8；合理 | 使用飞机航向，不是操纵杆 Yaw 输入；当前不直接评价机身 roll/pitch。 |
| 悬停 / -03 激光 | 靶面径向偏移；hit/miss/unavailable 分开 | 项目训练反馈 | 不独立对应官方 item；不能证明所有轴稳定，且与其他检查点相关。 |
| 垂直升降 / SCENE-VERTICAL-01 水平位置 | 升降阶段 X/Y | CP.IV.A.S4 的防漂移部分，合理但不完整 | **没有高度，无法判断是否上升/下降到要求位置**；后续悬停正确不证明中间过程正确。 |
| 垂直升降 / -02 航向 | 升降阶段 heading | CP.IV.A.S8 的部分映射，合理 | 与上一点共同只能评估升降期间的两种保持能力，不能覆盖垂直运动控制本身。 |

## 3. 运行中的反例核验

用审查时的 `Generate-SupervisorDemo.py` 熟练案例生成器和真实 `calculator.evaluate` 运行以下输入变换。未改原输入文件；只是内存复制的对抗探针。结果用于证明观测范围，**不是新演示样本或飞行真实性验证**。运行时量化仍为同轮审查前的固定 κ=3 演示参数；后续 CPT 变更可能改变分数，但不会消除这里的数据缺口。

**同轮用户随后澄清：停止阶段本来就应有很多帧，优先视为演示输入覆盖问题，不要求改系统采样设计。** 因此下列稀疏采样反例保留为审查观察，不转化为强制新增采样规则；原单帧 stop 是该澄清前的数据/目录状态，最终生成器与输入应以主任务更新后版本为准。

| 探针 | 操作 | 实际结果 |
|---|---|---|
| 进近期间根本没沿路线飞 | 保留273帧时间/阶段和原到点数据，把进近位置全部替换为终点 `(0,0,6)` | 无 issue；两个检查点 D，item D / Pass，97.0968785379分。 |
| 快停过程只给两帧 | 只保留快停第一帧和 stop 帧 | 无 issue；3检查点 D，item D / Pass，93.1894204173分。 |
| 升降缺少垂直运动证据 | 153帧 transfer X/Y/heading 全置0；按现行 schema 不提供 height/vz | 无 issue；2检查点 D，item D / Pass，97.0968785379分。 |
| 悬停5秒只观测两端 | 每次悬停只保留首末帧，总8帧，首末跨度仍5秒 | 无 issue；4检查点 D，item D / Pass，97.0968785379分。 |

第三个探针并没有断言飞机实际上没升降：**现行数据使“正确升降”和“完全没有升降/错误升降”无法区分**，系统却仍输出“垂直升降控制”高分。第四个探针同理，稀疏数据不证明中间做坏了，但也不证明连续5秒保持成功。

代码确实已经诚实区分首末时间跨度与连续观测，所以第四项是输入充分性提醒，不是当前代码违背已有注释。按用户决定，本轮先保证演示数据如实完整提供，不新增强制采样规则。当前 `phase_id` 也已检查合法顺序、场景公共时间顺序；**阶段标签顺序正确不能替代实际空间进度检查**。

## 4. D/A 数值与几何审查

以下只列当前演示设置，**不建议本轮无依据地重填数字**。所有 D 内圈和把 A 外边界视作及格边界的分档均为项目选择。

### 有直接数值锚点的 A 外边界

| 配置 | 当前值 | 可核对出处 | 边界 |
|---|---|---|---|
| 空中滑行高度 | ±3.048 m | [CP.IV.C.S5，PDF26](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf#page=26)：10 ft | 只锚定高度容差，不证明6m目标适用所有机型。 |
| 悬停高度 | ±1.524 m | [CP.IV.A.S5，PDF23](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf#page=23)：高于10ft时5ft | 下/上点6m和10m必须确实指AGL；若改成低于10ft，不能继续机械使用此分支。 |
| 悬停航向 | ±10° | CP.IV.A.S8，同页 | 目标方向仍由场景指定。 |
| 快停航向 | ±5° | [CP.VI.A.S3，PDF37](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf#page=37) | 不等价于横向位移，也不覆盖协调/减速性能。 |

ACS-17 AP.II.E.S5 的 ±10kt 约为 ±5.144m/s，而当前空速 A 为 ±1.5m/s、D为±0.5m/s。当前值更窄，但“更严格”不自动等于“更科学”；应保留为低速场景预设。尤其参考速度从0开始时，固定绝对容差在前段代表的相对误差很大，应在讲评中展示原始值，不把该容差等同统一百分比精度。[ACS-17原文，PDF19](https://www.faa.gov/training_testing/testing/acs/atp_pl_acs_17.pdf#page=19)

### 需要明确为项目选择的全部其余数值

| 组别 | 当前演示D / A | 判断 |
|---|---|---|
| 路线三维通道 | 0.6 / 1.5m半径 | 没有查到通用官方数值。圆柱/球帽式最近线段通道还不能代表路线方向和完成度。 |
| 到点及悬停/升降X/Y | 每轴±0.15 / ±0.4m | 若把官方2ft位置要求理解为水平半径，0.4m方框角点0.5657m小于0.6096m；这是保守几何解释，官方没有定义本软件方框。 |
| 到点高度 | ±0.2 / ±0.6m | 比持续悬停±0.5 / ±1.524m更窄，须说明“精确捕获起点”的场景目的。 |
| 到点/悬停各速度分量 | ±0.15 / ±0.5m/s | 工程稳定性指标；按轴最差并不等于对速度模长采用同样界限。 |
| 到点、空中滑行、升降航向 | ±3 / ±8° | 项目值；不能标成FAA统一8°。 |
| 空中滑行/快停横向 | ±0.4 / ±1.2m | 场景直线通道。 |
| 快停高度及停止高度 | ±0.3 / ±1m | 项目值，两个停止帧字段是同一物理高度，当前已有一致性校验。 |
| 停止X/Y | ±1 / ±3m | 固定终点任务要求，不是官方最大性能快停规定的停止距离。 |
| 激光径向偏移 | 0.3 / 0.8m；实体靶半径2m | 项目靶面几何；无权威D/A数字。对名义20m距离，0.8m仅约2.29°视线偏差，不能与允许±10°机头航向直接比较为相同难度。 |
| 悬停每次5秒，6/10m目标 | 用户场景设定 | 官方任务支持定点保持，未给出本项目5秒循环或6/10m通用目标。 |

原保速10秒的 D±0.2/A±1秒评分随本轮速度曲线修订删除；加速与保速曲线覆盖时长转成完整数据要求。具体新版速度曲线节点以本轮生成配置为准，而不由本审查另设。

还应注意两处重复：stop 高度同时进入终点与过程检查点；hover 激光在当前合成几何中同时受高度、水平位置、航向影响。分别显示它们有解释价值，但等权量化并不自动消除相关性。不能用“每个检查点等权”证明所有技能维度权重相等。

## 5. 建议的最小后续修订，不扩大成检测系统

1. **急停：** 保留3个检查点的总体简洁度，把“停止位置精度”扩为“末端停止状态”（位置+水平地速），把速度减小过程并入“减速过程控制”。沿用用户已批准的首帧相对时间/参考曲线机制是一种候选，但应与终点距离和入口速度保持物理一致。不给最大减速度通用数值；若用户要保留“最大性能”含义，必须等机型性能目标到位。
2. **垂直升降：** 候选为在当前 item 中加入一条高度参考曲线，评价高度随时刻的变化，并可用原始 vz 辅助解释；或者定义高度方向与端点捕获而不固定每秒时刻。两者是不同训练要求，不能由系统悄悄替用户选择。先保留XY/heading原有维度。
3. **进近：** 独立保留逐帧航迹距离；增加沿折线的进度、入口与终点覆盖。存在自交或相邻路线段时，还需避免最近点任意跳段。这是几何评价，不是事件检测。若只维持当前版本，报告名称应明确为“进近空间通道保持”，不要宣称已完整评估稳定进近。
4. **演示输入完整性：** 遵循用户最新澄清，在停止阶段提供连续多帧，在其余已有过程阶段同样提供完整过程。本轮不强制新增采样频率/最大间隙验证设计，也不为缺口插值出“合格”的观测。方法说明保留“帧占比只有在等间隔或已明确采样策略时才近似时间占比”。
5. **限制与协调：** 当前general版本可以保留范围较窄的声明。未来机型已知后，新增数据也仍是外部给定的原始值/事件结果；无需在本系统做视觉识别、阶段切片或操纵事件检测。不要从激光或航向独自推断侧滑、滚转/俯仰载荷、功率或包线都合格。

本轮不建议把“所有官方条款”全部拆成新检查点；优先补上现有 item 名称已经声称、但数据尚不能证明的能力。

## 6. P/F 与综合表现分数的说明

用户要求“任一检查点出现U保留Fail、综合水平另给分数”可以作为明确的训练规则继续使用。官方判定不是逐帧阈值自动机：FAA ACS-2 Appendix1在PDF68列出持续超差、未及时纠正等情况；CAA §3.1.2则明确单次越过指导容差不必然等于考试失败。[FAA原文](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf#page=68)、[CAA原文](https://www.caa.co.uk/publication/download/12966#page=14)

因此训练报告应继续让用户看到三个不同事实：**哪项要求被违反、整段表现水平是多少、失误何时发生及如何恢复**。分数可以随良好表现恢复，Fail记录仍保留；不要把高综合分解释为已经满足全部官方考试要求。

累计过程分数在后段必然更不敏感，因为新增一小段表现只占此前全部数据的一小部分。这是累计含义本身；若需要看“当下表现波动”，应另显示局部指标/原始值，而不是仅调CPT让累计分数产生人为振荡。本结论来自累计计算结构，不是航空标准条文。
