## 当前概率计算与参数

内部数组统一为低／中／高，配置 `prior` 给出首次先验。每个有效帧先用 CPT 对应观测列得到似然 L，计算 `q[s]=prior[s]×L[s]/sum(prior×L)`，再计算 `p[s]=(1−α)×q[s]+α×target[s]`。下一帧使用 p 作为先验；阶段切换不重置。检查点各自更新自己的概率；item 将该帧所有适用检查点的 CPT 似然相乘后更新一次，不把检查点后验再次相乘。

D、A、U 的补偿目标分别为 `[0,0,1]`、`[0,1,0]`、`[1,0,0]`。item 的目标取本帧适用检查点的最差等级。补偿变化量是 `α×(target−q)`：α 固定时，当前 CPT 后验与新观测目标差得越远，实际概率修正越大。α=0 为无补偿贝叶斯，α=1 完全采用本帧等级；默认演示值 α=0.2，可在 item 模型编辑器修改。

`score=sum(p×state_scores)` 仅作概率显示映射；演示采用低／中／高对应 0／50／100 分。分值锚点不进入概率递推。每帧明细保留 `prior`、`bayes_posterior`、`compensation_target`、`compensation_alpha`、`compensation_delta`，以及最终 `posterior` 和 `score`，可区分 CPT 与补偿各自的作用。原始 CPT 的 log BF 仍仅表示似然证据，不包含补偿。

此模型输出的是包含补偿的序贯状态，不能称为未经修正的纯贝叶斯后验。连续 D 仍可能接近高档概率 1，但随后 U 可以重新注入低档概率。六例原输入实算中，不合格案例后段恢复后，末帧模型分数也可接近 100；原 Fail 与失误过程仍可查看。这不是整段质量排名。多个检查点共同推断时，其他检查点的好证据与最差等级补偿会共同作用，因此不承诺每个含 U 的 item 帧必定降分。

α 按有效帧应用，完整 CPT 也按帧更新，采样率会影响响应；不补造帧间时间或证据。缺测继续阻断完整概率输出。先验可手工设置，但本轮未实现学员账户与跨训练状态自动继承。

已知旧 v3 配置加载后自动使用新方法，保留先验、CPT 和分值，删除旧过程参数，并在未配置补偿时使用 α=0.2。已有新法 α 完整保留；未知方法或错误数据仍提示问题，不擅自猜测。导出配置只保存新法，原文件不会被自动覆盖。旧报告仅为历史文件，需重新评估得到新版过程和分数。

## 期望值与正负容差

输入 JSON 在每个 item 内按帧组织，同一帧包含本阶段适用检查点的原始值。系统按“实际值 − 期望值”计算有符号偏差。航向取 [−180°,180°) 内的最短角差，例如期望 359°、实际 1°，偏差为 +2°。实际值和期望值必须采用同一单位和参考系。

编辑器用“允许低于期望值”“允许高于期望值”解释 D/A 容差，界面输入非负的允许量；JSON 仍保存有符号 lower/upper（例如允许低于 2 对应 lower=-2）。两侧可以不对称，D 包含于 A，端点属于区间内。无依据的目标和容差留空；停住速度的期望 0 是状态定义，速度容差仍需填写。

例如期望 100、D=[−2,+2]、A=[−5,+5]：实际 98 判 D，103 判 A，106 判 U。这仅解释软件规则，不是航空或人因推荐阈值。

起飞前检查读取六类检查完成情况：电池与供电、推进与功率、飞控与起飞构型、飞行仪表、告警与系统状态、导航与任务信息。true 判 D，false 判 U，null 表示缺数据。具体项目仍按机型检查单落实；true 表示检查已完成，不自动表示设备正常。不再读取眼动停留秒数，不计算检查单熟练度概率。

## 加速减速任务范围

用户已确认真实任务不存在“正常进近至悬停”阶段，当前 SCN-001 删除 A-S2-23、其三个阶段和八个输入量。飞行评分覆盖加速与保速、快速减速／快速停止；确认结束仅标记任务边界，不新增能力 item。起飞前检查单本轮保留，后续另行讨论其在真实数据验证中的使用方式。

当前内部阶段顺序为 preflight → acceleration → hold → deceleration → stop。实际采集 phaseID 1 包含加速与保速，phaseID 2 包含减速与停止后观察，phaseID 3 为确认结束；本轮没有实现 CSV 转换或阶段细分，评估器仍接收上游已整理的 item.frames。

“快速减速／快速停止”的官方英文名称为 **Rapid Deceleration/Quick Stop**，见 FAA-S-ACS-2 Area VI / Task A，CP.VI.A.S3–S6（印刷第32页，PDF第37页）。官方内容包括保持航向、在机型限制内最大性能减速、选择合适功率和推力方向、保持协调飞行；并不等于电机最大功率或操纵杆推满。目前系统仅保留停止位置精度、减速过程控制、限制与禁止接触三个检查点，指定停止位置是项目要求，不能宣称完整覆盖 FAA 最大性能任务。停止检查目前没有地速量，输入 stop 标签不能单独证明已经停稳；检查方法将在后续逐项讨论。

旧 v3 配置或输入仍含 A-S2-23 时会被明确拒绝，不静默删改用户数据。请加载[本轮六例演示包](../../examples/task-scope-2026-10-11/README_CN.md)或使用新的空模板；九月演示和先前进近方法文档保留为历史记录。通用三维路线计算引擎仍可供未来有相应阶段的场景使用。

## 空中滑行：加速与保速速度控制

`A-S2-05-01`「加速与保速速度控制」逐帧读取 `air_taxi_airspeed_mps`，覆盖 `acceleration` 和 `hold` 两个阶段。它用同一条期望空速曲线评价加速落后、超调和保速偏离；不再只比较保速阶段，也不再单独给“保速时长”打 D/A/U。高度、横向位置和航向仍分别检查，速度贴合程度不能单独代表全部操纵质量。

点击 item 的参数编辑入口，在一张表中填写“加速开始后 / s”和“期望空速 / m/s”。至少两个完整节点，首节点时间必须为 0，后续时间严格递增。节点可以添加、删除；空列表或未填完的节点可保存为草稿，但不能完整评估。D/A 仍填写“允许低于／高于期望值”，色带沿期望曲线上升并进入保速平台。

配置采用 `expected: null` 和单一 `reference_profile: [{"elapsed_s": ..., "expected": ...}, ...]` 列表。指标元数据为 `target_mode: "item_profile"`、`reference_origin_phase: "acceleration"`。曲线由场景设计者填写，不根据学员输入拟合。

系统把该 item 中 `acceleration` 的第一帧时间作为唯一 `t0`，每帧参考时间为 `timestamp_s − t0`。例如加速首帧为 28.3 s，30.7 s 的实际帧对齐曲线 2.4 s；进入 `hold` 后继续使用同一个 `t0`，不重新归零。参考节点之间线性插值，例如 2 s 对应 4 m/s、6 s 对应 10 m/s，则 2.4 s 的期望空速为 4.6 m/s。这只是算术示例，不是推荐训练曲线。

每个实际帧用“实际空速 − 插值得到的期望空速”判断 D/A/U。软件只插值参考曲线，不插值、重采样或拉伸输入帧。报告保留实际 `timestamp_s`，该指标另外记录 `reference_elapsed_s`；图表明细同时显示原始时间和加速开始后的时间。参考节点数量不增加评估帧数或贝叶斯证据数量。

数据完整性需要单独满足：缺少加速起点阶段时，不用第一帧保速数据代替起点；输入结束早于参考曲线末端时，提示过程覆盖不足；实际帧超出曲线范围时，不外推或沿用端点目标。上述情况不能形成完整 Pass 或最终量化分数，已经观察到的 U 仍保留。首末时间覆盖也不能证明中间采样完整。输入提供方必须记录真实加速开始帧：若实际已开始加速但早期帧未提供，仅凭剩余数据无法自动识别这种漏录。

官方条款支持速度控制、指定航迹和受控操纵的考查；“第几秒达到多少空速”、本软件的参考曲线和 D/A 允许量是场景训练目标，须事先告知学员，并按飞行器能力和训练要求另行确定。依据范围见[加速速度参考审查](reviews/2026-09-15-acceleration-speed-reference-review.md)。

## 定点悬停保持

SCN-002 的 `A-S2-02`「定点悬停保持」统一检查水平位置、高度、航向和激光。高度是定点悬停的一部分，保留为可追溯的检查点，不再单设高度 item。

| 检查点 | 需要的当前帧原始值 | 检查内容 |
|---|---|---|
| 水平位置保持 `A-S2-02-01` | `hover_x_m`、`hover_y_m`、`hover_vx_mps`、`hover_vy_mps` | X/Y 逐分量比较目标位置，水平速度比较近零目标，检查是否定点并停稳。 |
| 悬停高度保持 `A-S2-02-04` | 当前阶段的 `hover_lower_height_m` 或 `hover_upper_height_m`，以及 `hover_vz_mps` | 检查相对当前目标的高度偏差及垂直运动；上下目标分别配置。 |
| 航向保持 `A-S2-02-02` | `hover_heading_deg` | 检查机头方向的最短角差，速度不重复放入此检查点。 |
| 激光指向保持 `A-S2-02-03` | 当前阶段的 `laser_lower_spot` 或 `laser_upper_spot` | 检查应评圆盘的命中状态和距靶心半径。 |

每次悬停同一帧包含当前高度、X/Y、三个速度分量、航向和当前激光落点，共 8 个适用指标值。下方阶段不要求上方高度/光点，上方阶段同理。每个指标保留自己的 D/A 容差，检查点取同帧适用指标的最差档；这里没有 X/Y/Z 合成距离，也不以激光命中代替高度或位置检查。缺失高度不会从旧独立 item、相邻帧或速度推算。

四检查点共同进入一份悬停 item 的贝叶斯模型。原整段演示评分方法按四个检查点等权计算整项结果，各占 1/4；高度不再游离于定点悬停分数之外。修改高度表现会改变高度检查点的档位分布和本 item 的演示后验。结果窗口展示整项累计分数，以及四个检查点各自的完整原值过程；分数不能消除任何已知 Fail。新增时序过程分析使用下文的条件似然累计规则，不复用这里的 1/4 权重或固定证据强度。

依据上，[FAA-S-ACS-2 CP.IV.A.S5/S6/S8](https://www.faa.gov/training_testing/testing/acs/commercial_pl_acs_2.pdf#page=23)在同一悬停机动任务内分别检查高度、位置和航向；[EASA FEM Module 3.3，第10页 Section 2(c)及第20页](https://www.easa.europa.eu/en/downloads/138658/en)与[CAA03(H) V6，第18页 Section 2(c)](https://www.caa.co.uk/publication/download/12966#page=18)提供定常悬停同时保持这些维度的交叉参照。四个检查点的拆分、速度补充、激光和每次 5 秒流程都是项目适配，不代表官方逐项规定了该软件结构、D/A/U 或 CPT 数字。详见[合并合同](plans/2026-09-15-hover-item-consolidation.md)。

## 时序输入

根对象包含 schema_version、scene_id、items。每个 item 内只有 frames；每帧包含 timestamp_s、phase_id、values，可选 controls。timestamp_s 是整个场景统一仿真时钟的非负相对秒，不能在每个 item 或每次悬停重新从零计时。完整字段由当前场景模板和 item 编辑器提供。

每个 item 内时间严格递增，阶段顺序按目录排列。阶段和所属原始值已由输入明确，软件不识别开始/停止事件，不切分完整日志，不排序、插值或补充观测帧。起飞前检查单使用指定单帧；持续阶段要复制相应占位帧并填写完整序列。`stop` 现在允许多帧，已没有 `hold_end` 阶段。输入时间戳仍使用统一场景时钟，参考曲线的相对计时只在计算和报告字段中表达。

场景还检查阶段时间是否一致：下方悬停、上升、上方悬停等不能被拼成倒序或重叠的时间。合并后高度与水平位置来自定点悬停 item 的同一帧，不需要在两个 item 间对齐悬停时钟。矛盾输入提示缺项/错误，不给完整通过。不同阶段之间的未提供时间不补齐。

定点悬停 item 包含 lower_1、upper_1、lower_2、upper_2；每次要求首末帧覆盖至少 5 秒。这个跨度检查不证明帧间连续状态或采样质量，不自动重置计时或选择最好的 5 秒。升降 item 包含 rise_1、descend_1、rise_2；继续检查升降期间的 X/Y 漂移及航向，目标高度由随后悬停的高度检查点负责。

加速减速的空速在 `acceleration` 和 `hold` 每帧都与共享参考曲线比较，详见上节。快速减速 item 只有 `stop` 阶段需要终点 X/Y/高度，`deceleration` 帧不与终点比较；过程高度／航向／横向位置与已认定禁止事件继续评价。

`stop` 可提供按时间递增的连续多帧；各帧都评价终点位置及该阶段适用的过程指标，任何已知 U 都参与最终最差档汇总。此次仅取消“只能一帧”的限制，没有新增最少帧数或停留时长要求。导师演示使用 5 秒、51 帧，这是演示设计，不是官方或通用通过条件。当前终点位置检查只说明位置误差：**位置接近目标以及输入标注为 `stop`，都不等于系统已验证地速为零**；此阶段尚未加入地速检查，也不从相邻位置差分推算地速。

stop 帧中的停止高度和过程实际高度代表同一原始量，须一致；系统提示矛盾但不替你改值。各检查点的目标和容差仍分别配置。

controls 可包含 Pilot Lon、Pilot Lat、Pilot Yaw、Pilot Heave。它们是操纵输入，原样保留作解释；评分使用实际状态，不以少动杆或杆量为零判好。

## 激光圆盘

定点悬停 item 中，上下靶各有独立的圆心 u/v、D 半径、A 外半径及实体靶半径编辑项。两靶几何由用户手动镜像仿真场景。

每帧落点值为 `{ "status": "hit", "u_m": 0.1, "v_m": 0.0 }`；明确未命中应评靶使用 `{ "status": "miss", "u_m": null, "v_m": null }`。null 或 unavailable 表示缺数据。这里的坐标仅解释格式，不是阈值建议。

计算 r=sqrt((u-center_u)²+(v-center_v)²)：r≤R_D 为 D，R_D<r≤R_A 为 A，r>R_A 或明确脱靶为 U；要求 0≤R_D<R_A<实体靶半径。激光结果和位置、速度、航向共同评价；光点 D 不抵消实际位置 U。缺测不当作脱靶。

## 报告

数值逐条先判 D，未满足再判 A，否则 U。检查点、item 和 Task 保留最差档：D/A 对应 Pass，U 对应 Fail；后续恢复不会抹去已知 U。数据不足时不制造完整 Pass，也不把缺失本身判作飞行员 U。

点击评估后的 item，打开可调整大小的独立结果窗口。窗口按目录顺序排列检查点，展开后展示各指标完整时间轴；多个指标按各自单位分别成图，以相同 item 起止时刻对齐。每图为实际观测线、期望虚线、D绿色内带和A浅黄色外带；U在A带之外，仍能看到实际偏离幅度。标量边界是期望值加上对应的有符号允许偏差，绝不直接把偏差界限误画成原值界限。

航向按相对目标展开的等效角度绘制，避免0/360度交界出现假跳变，原始角度仍在明细中。激光用到靶心距离、进近航迹用到预设路线距离作纵轴；明细保留u/v或实际三维位置及最近路线点。明确脱靶没有虚构的距离值，用事件标记显示；检查单用真实时刻和完成状态表示。所有真实帧均可追溯，不把同一档位内的真实小波动抹平。阶段之间、缺值和不适用区间留空，单帧仅显示真实点；连线辅助阅读，不表示帧间存在额外采样。

frame_distribution 的 counts/proportions 是有效帧计数及比例，missing_frame_count 显示不能判档的已提供帧；未记录的帧数不能由系统猜出。无有效帧时各比例为 null。各阶段另有 observed_span_s，表示首末帧时间差。**帧占比不冒充时长占比**，本版不推断某帧状态持续到下一帧。每帧必需量取最差档，最终 U 不因后续恢复消失；此严格汇总是项目规则。

## 贝叶斯模型

四个飞行 item 的先验、状态分值和检查点 CPT 可以编辑、保存和回读。CPT 表示 P(检查点 D/A/U | item 状态)，完整填写的每行概率之和必须为 1。新模型数值初始为空，不阻塞规则评估。定点悬停的四份 CPT 对应水平位置、高度、航向、激光；同一个原始指标不在多个检查点重复用作证据。

**技能推断模型仍未经过真实飞行员数据标定。** 当前新模板采用本文开头的贝叶斯＋补偿；填写完整参数后即可运行。激光、位置、高度和航向可能相关，item 中相乘似然使用的是未验证的条件独立假设。Task 没有 CPT 或能力总分。

## 历史文件与旧输入格式

软件不再执行旧 κ、τ、局部窗口或静态 EAP 算法。历史导出报告及研究说明仍可查阅，但它们不是当前软件的计算结果。已有逐帧 v3 配置自动转为新法后重新评估；v1/v2 非逐帧输入只支持其原规则检查，不再推断旧能力概率，需要提供逐帧输入才能使用当前模型。
