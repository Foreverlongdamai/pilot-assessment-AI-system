## 0. 结论

现行方法把每一帧（100 Hz）当作一份独立证据，再每帧向当前档位补偿20%，结果只记得最后约5帧，且随采样率变化。建议整体改为评估领域成熟的“证据中心设计”（ECD）做法：

1. **证据按次计入，不按帧计入。** 每次动作中，每个检查点由规则概括成一个结果，在结果形成时进入网络一次。100 Hz的逐帧档位只用于复盘显示。
2. **CPT用分档反应模型生成。** 每个检查点只有两类参数：区分度 a（证据强度）和阈值 b（档位位置），默认 a=1、b=±0.605。单个U对“高／低”的对数似然比从现行的−6.5降为−2.3。
3. **能力层改为9个等概率格点。** 先验各1/9，低／中／高三档各含3个格点（先验各1/3），现行三状态是它的特例。
4. **分数改为“预期检查点得分”。** 即该能力水平下每个检查点预期得到的D=100、A=50、U=0分数的平均，随证据增多收敛到飞行员的长期平均得分，不再塌到0、50、100。同时报告标准差和三档概率。
5. **两种结果分开。** 本次表现分每次从同一先验计算；能力档案跨次传递，同一次训练内能力不变，两次训练之间按天增加不确定度，90天后回到先验。
6. **门控不变。** P/F按规则非补偿判定，分数不改写门控。

65趟实采试算：结果与采样率无关（100 Hz与10 Hz三档结果完全相同）；分数随证据组成单调变化，与各检查点得分平均的秩相关0.975；格点数取7～41之间时分数最多差1.3分；检查点之间没有显著的局部相关；单次动作的边际信度0.69，同一次训练4个实例合并为0.91；单次计算7.6 µs。主要局限是参数为设计值、不由数据标定（单一飞行员数据无法区分检查点难度与本人弱项），详见第8.6节。

## 2. 现行方法的问题

| 问题 | 数据（讨论稿9.1及文献调研第4节） | 原因 |

| 重复动作无规则 | 定点悬停4次、垂直升降3次如何汇总未规定 | — |

## 4. 网络结构

以场景一“受控减速与定点停止”为例。其他科目结构相同，只是检查点不同。

```
输入层   X/U 9路信号，100 Hz（位置、速度、航向、纵横向杆量等）
   │  证据识别（规则，单个动作内完成）
特征层   15个观测量（横向偏差、航向差、B、H、推拉次数、初次停住点ΔX/ΔY、挪动次数……）
   │  检查点规则：D/A/U（或IATA五档）
证据层   E1 减速航迹与航向 │ E2 减速平顺性 │ E3 初次停住点 │ E4 末端修正（需要修正时）
   │  CPT：分档反应模型，权重 W[k,g,j] = ln P(E_k = g | θ_j)
能力层   θ₁ … θ₉（9个等概率格点）→ 低（θ₁–θ₃）／中（θ₄–θ₆）／高（θ₇–θ₉）
   │  输出：能力分（后验期望）、标准差、三档概率；每条证据的证据权重
档案层   跨次训练传递：同次训练内不变；两次训练之间按天增加不确定度

门控（并列）：检查点一（最终停点）与检查点二（减速航迹）按规则判P/F，不经过网络
```

### 4.1 每层的数量与更新频率

| 层 | 节点 | 更新时刻 |
|---|---|---|
| 输入层 | 9路 × 100 Hz | 每帧 |
| 特征层 | 15个观测量 | 所属阶段或事件结束时形成 |
| 证据层 | 4个检查点，每个3档（独热12维）；E4按条件出现 | 事件驱动：E1、E2在主减速段结束，E3在初次停住，E4在phase 2结束；每次动作3～4次 |
| 能力层 | 9个格点 | 每条证据到达时更新一次 |
| 输出层 | 能力分、标准差、低／中／高概率 | 同能力层 |
| 档案层 | 9个格点 | 每次训练结束；训练之间按天增加不确定度 |

### 4.2 与神经网络的对应（供导师汇报）

能力层的计算就是一层固定权重的softmax：

`p_j = softmax_j( ln π_j + Σ_k W[k, x_k, j] )`，能力分 `= Σ_j p_j · s_j`

输入是证据层的独热向量，权重 `W[k,g,j] = ln P(E_k=g | θ_j)` 由每个检查点的2～3个参数生成（4×3×9=108个权重，来自3个共享参数），输出层是固定的线性层。和训练出来的神经网络不同，这里每个权重都有明确含义，不需要标注数据训练。

## 5. 逐层设计

### 5.1 全过程分析：把一次动作的100 Hz过程变成每个检查点一个结果

全过程分析是ECD的“证据识别”（evidence identification），在单次动作内完成；网络部分是“证据累积”（evidence accumulation），在检查点、实例和训练之间完成。HYDRIVE、NetPASS、Physics Playground、SimCityEDU均如此分工（文献调研第2节）。两层的分工：

| | 全过程分析（证据识别） | 贝叶斯网络（证据累积） |
|---|---|---|
| 范围 | 一次动作内，一个检查点 | 一个科目的全部检查点、全部实例、多次训练 |
| 输入 | 100 Hz原始信号 | 每个检查点每次动作一个档位 |
| 方法 | 规则：窗口、逐帧量、片段与事件、维度汇总、定档 | 概率：CPT似然相乘、归一化 |
| 输出 | 过程曲线、色带、片段与事件清单、各维度数值、档位及定档理由 | 能力分、标准差、三档概率、证据权重 |
| 用途 | 复盘与具体改进意见（R7） | 能力水平与档案 |

不把逐帧档位直接送进网络：相邻帧高度相关，按帧计入相当于把同一个偏差重复计数数百次，这正是现行方法采样率差24.5分、只记得最后约5帧的原因。

#### 5.1.1 每个检查点的五步

| 步骤 | 内容 | 产物（报告中保留） |
|---|---|---|
| ① 定窗口 | 按阶段与事件确定观察范围，如主减速段、初次停住时刻、phase 2结束 | 窗口起止时刻及识别依据 |
| ② 逐帧量与逐帧档位 | 每帧计算误差或特征，按D/A带判档 | 过程曲线与D/A/U色带 |
| ③ 片段与事件 | 超差片段（起止、持续、峰值、是否在规定时间内修正）；操纵事件（推拉、无效修正、反复修正、挪动） | 片段与事件清单，带时间戳 |
| ④ 维度汇总 | 按IATA CBTA的维度汇总：多频繁（时间占比、片段数）、多严重（峰值、持续时长）、结果（末状态） | 各维度数值 |
| ⑤ 定档 | 按预先写定的规则得到一个档位（三档或五档），记录由哪一条规则决定、在什么时刻定档 | 档位、定档理由、定档时刻 |

步骤④⑤的依据：FAA ACS附录把“持续超出容差”“未及时修正”列为不合格（FAA-S-ACS-13附录，PDF第72页）；IATA CBTA以多个维度中最低者定档（GM §8.2–8.3、§9.1–9.2）；Rahimi等对时长类观测量先按范围评分再送入证据累积；Sun等2023把仪表飞行程序分阶段评分后汇总为CBTA等级（文献调研第6节）。

#### 5.1.2 四类检查点

| 类型 | 特点 | 五步中的重点 | 受控减速与定点停止中的例子 |
|---|---|---|---|
| 过程型 | 整个窗口内持续要求 | ②③④：时间占比、超差片段、是否及时修正 | E1 减速航迹与航向 |
| 操纵型 | 看输入与响应 | ③：输入事件分类，与响应对齐；输入与响应合并为一个结果，不重复计入（讨论稿8.7第4点） | E2 减速平顺性（B、H、推拉次数） |
| 结果型 | 某一时刻的状态 | ①⑤：准确识别事件时刻，再按边界定档 | E3 初次停住点 |
| 条件型 | 只在特定情况出现 | 先判断是否适用；不适用不计入，不算缺失 | E4 末端修正 |

过程型检查点的定档规则按D-015（2026-11-17已确认）：连续超出A带超过1 s判U；超出过A带但每次1 s内回到A带内，或超出D带累计超过1 s，为A；超出D带累计不超过1 s且从未超出A带，为D。D带内时间占比不再用于判D。其他科目的保速、悬停保持等过程型检查点沿用这一结构，边界与时间阈值随各科目设计确定。

证据在原生采样率上计算。10 Hz重算时三档结果65趟完全相同；五档中的推拉次数对采样率较敏感（8.3节）。

### 5.3 CPT：分档反应模型

每个检查点 k 的条件概率由Samejima分档反应模型生成：

`P(E_k ≥ c | θ) = 1 / (1 + exp(−1.7·a_k·(θ − b_{k,c})))`

| 参数 | 默认值 | 依据 |
|---|---|---|
| 区分度 a | 1.0（1.7缩放后的logistic，约等于正态肩形模型斜率1） | Almond等（2013，pp.5–6）：区分度约1为常见，高于2多提示估计困难；Almond（2015）的GRM式CPT同样使用1.7缩放。换到Baker（2001，表2-4，第34页）的logistic尺度为1.7，处在“高”（1.35–1.69）与“很高”（>1.70）的分界，属于偏强的一端；改用a=0.7（Baker尺度1.19，“中等”）时65趟分数平均变2.2分、排序不变（8.2节），单次动作信度由0.69降为0.53（8.3节）。按Kass与Raftery（1995）的贝叶斯因子分级（2lnB：2～6正面，6～10强，>10很强），一个检查点结果对“高／低”为2lnB=4.6，属“正面”；两个一致结果8.7，属“强”；三个12.6，属“很强”。现行CPT一个U就达到13.0，相当于本方案三个一致结果。不让单次单项结果决定能力判断 |
| 阈值 b（三档） | U｜A边界 −0.605，A｜D边界 +0.605 | “众数对应”原则：低档飞行员最可能得U，中档最可能得A，高档最可能得D，且A为最可能档位的能力区间恰好等于中档。在 a=1 下解得 b₀=0.605 |
| 阈值 b（五档，可选） | −0.605、0、+0.605、+1.209 | 五档按IATA嵌套（1→U，2–3→A，4–5→D），U｜A与A｜D两条边界与三档相同，档内再等距细分。三档与五档使用同一分数尺度 |
| 共用还是逐检查点 | 默认所有检查点共用；Model Studio可逐检查点修改 | 各检查点的D/A/U已按条款、文献与数据分别定义为“期望／可接受／不可接受”，含义相同；单一飞行员的数据无法区分“检查点更难”与“本人这一项更弱”（见8.6第2条） |

|---|---:|---:|---:|---:|---:|
| 1（低） | −1.59 | .843 | .134 | .023 | 9.0 |
| 2（低） | −0.97 | .649 | .286 | .065 | 20.8 |
| 3（低） | −0.59 | .494 | .390 | .116 | 31.1 |
| 4（中） | −0.28 | .366 | .452 | .181 | 40.7 |
| 5（中） | 0.00 | .263 | .473 | .263 | 50.0 |
| 6（中） | +0.28 | .181 | .452 | .366 | 59.3 |

|---|---|---|
| 低 | .65 / .25 / .10 | .66 / .27 / .07 |
| 中 | .02 / .63 / .35 | .27 / .46 / .27 |
| 高 | .001 / .099 / .90 | .07 / .27 / .66 |
| 一个U对“高／低”的对数似然比 | −6.48（2lnB=13.0，“很强”） | −2.28（2lnB=4.6，“正面”） |

主要变化在两端：现行CPT认为中档飞行员几乎不会得U（2%）、高档几乎不可能得U（0.1%），所以一个U就足以否定“高”。本方案让一次U降低判断，但不单独决定结论。

**加大权重的证据（D-023，2026-11-18）。** 用户确认：受控减速与定点停止的最终停点精度单独进入网络，“不可接受”的影响权重要加高。

**可选做法**（试算脚本 `tmp/bn_plan_2026-11-17/grm_bn.py` 的 Model 类）：

|---|---:|---:|---:|
| 普通证据（区分度1） | 4.6，正面 | 4.6 | 30.2 |

| 区分度2 | 9.2，强 | 9.2 | 16.4 |

**初步建议：** 区分度取2，一个“不可接受”相当于两个一致的普通结果。

**取舍：**
- 只移动“不可接受”的边界几乎不增加它的影响；
- 分档反应模型中，区分度同时加强“不可接受”与“期望”两端，最终停点准确的飞行也会相应得到更多加分。

具体取值随网络方案一并确认。

### 5.4 能力层：9个等概率格点

- 格点 `θ_j = Φ⁻¹((j − 0.5)/9)`，即标准正态的9个等概率区间中点；先验各1/9，相当于先验N(0,1)。
- 低／中／高三档为先验三等分（θ切点±0.431），每档3个格点，先验各1/3，与现行均匀先验相同。
- 格点数取3时得到 θ = −0.97、0、+0.97，正是Almond三状态的“有效θ”，现行三状态模型是本方案的特例。
- 选9个格点的依据：Bock与Mislevy（1982，第433页）用离散先验上的求积点计算EAP，并指出“In any given quadrature only about 10 of these points need to be used”；Haberman、von Davier与Lee（2008）比较潜变量分布的离散化，7、9、11个等距点与正态潜变量的拟合差异很小；本方案实采试算中7～41个格点的分数最多相差1.3分（8.2节）。9个格点也便于画成神经网络样式。

### 5.5 更新

一次动作中证据依次到达，每到一条：`ln p(θ_j) ← ln p(θ_j) + ln P(E_k = x | θ_j)`，再归一化。先验只在开始时用一次。给定能力时，同一动作内的检查点结果条件独立（8.3节Q3检验支持）。整段结果与证据到达顺序无关。

| 10.5 s | E1 = D | +1.36 | 69.8 ± 19.6 | .07 / .27 / .66 |

### 5.6 输出与解释

| 输出 | 计算 | 含义 |
|---|---|---|
| 能力分（0～100） | `Σ_j p_j · s_j`，`s_j` 为格点 j 的预期检查点得分 | 该能力水平下，每个检查点预期得分（D=100、A=50、U=0）的平均，即IRT的期望分 |
| 标准差 | 能力分的后验标准差 | 单次动作约±9～18分；证据增多而缩小 |
| 低／中／高概率 | 各档3个格点的后验之和 | 与现行三档概率含义一致 |
| 证据权重 | `WOE_k = ln P(E_k=x | 高) − ln P(E_k=x | 非高)` | 每条证据把“高”推高或拉低多少：D为+1.36，A为−0.30，U为−1.93 |
| 检查点诊断 | 多次动作中该检查点的实际得分率减去模型期望 | 正值为相对强项，负值为要提高的方面 |

能力分不再用状态分0/50/100加权。原因有三：它的含义（期望得分）可以直接说清；它不随格点数变化（格点线性映射在J=9与J=41之间相差最多8分）；证据充分时它收敛到飞行员的长期平均得分。例如70%D/20%A/10%U的稳定表现，各档平均得分为80分，本方案给出78.0（10条证据）→79.2（20条以上），现行三状态在1000条证据时给50分。

能力分的范围约为9～91分。即使最高能力格点，期望也有约16%的检查点得不到D；单次动作证据有限，全D的一次动作给85.5±8.8分、高档概率0.97。多次动作的档案会继续收紧。

### 5.7 重复实例

- 定点悬停4次、垂直升降3次等同类实例，在同一次训练中共享一个能力，按时间顺序依次计入（SimCityEDU：同一挑战内能力不变）。
- 报告同时给出每个实例单独计算的结果（共同先验加该实例证据），用于比较四次悬停或三次升降。
- 必做实例缺失时按5.10处理，不补为D。

### 5.8 两种结果：本次表现分与能力档案

| 结果 | 先验 | 用途 |
|---|---|---|
| 本次表现分 | 每次训练从共同先验开始 | 本次训练的评分与反馈；不同次训练之间可直接比较 |
| 能力档案 | 上次档案经时间衰减后作为本次先验 | 训练进展、是否需要再训练 |

档案的时间衰减用一阶自回归：`θ_t = ρ·θ_{t−1} + √(1−ρ²)·ε`，平稳分布等于先验，所以长期不训练会回到“未评估”状态。

- **同一次训练内 ρ=1（能力不变）。** 65趟按时间顺序拟合，ρ=1的边际似然最高（−247.6；ρ=0.99为−249.4；ρ=0即每次独立为−262.6），分数与顺序的秩相关0.02，这一天内没有检测到能力漂移。
- **两次训练之间 ρ_day = 0.9835/天（时间常数60天）。** 设计规则：不训练90天后，档案的不确定度回到先验的95%。90天取自两项近期经历要求：EASA FCL.060(b)(1)（适用于powered-lift与VTOL-capable aircraft）要求载客或商业运输前“in the preceding 90 days, at least 3 take-offs, approaches and landings as a pilot flying in an aircraft of the same type or class or an FFS representing that type or class”（EASA Easy Access Rules for Aircrew，Nov 2025版，第108–109页）；FAA 14 CFR 61.57(a)(1)要求机长载人前90天内在同类别、级别和型别航空器上完成3次起飞和3次着陆。做法对应Glicko评分系统“不确定度随未参赛时间增大、按设定期限回到未评级水平”，以及Wang、Berger与Burdick（2013）动态项目反应模型中能力随机变化项的方差与两次测试间隔成正比。技能随停练时间衰减的证据：Arthur等（1998）汇总53篇文献，效应量从训练刚结束的−0.01到停练365天以上的−1.4，停练间隔与衰减的相关为−0.51（基于8个间隔类别）。按此规则，65趟后的档案（46.8±4.4）不训练7天变为±14.9，30天±22.5，90天回到三档约各1/3。

这也修正了PPT第59～60页“上次后验直接作为下次先验”的说法：上次后验要先经过时间衰减再作为先验。只有能力不变时直接传递才成立；训练之间能力会变化（文献调研第8节：Khajah等2016指出没有遗忘时，一旦推断已学会，再长的失败序列也难以改变判断）。

### 5.9 门控与分级

- P/F按规则非补偿判定：交接3.2建议检查点一、二参与门控，检查点三、四只分级。这一选择也化解了“初次停住点判U的29趟若参与门控会与D-003矛盾”的问题。
- 分数不改写P/F。实采中门控Fail的17趟分数为14.5～50.0，门控Pass的48趟为27.7～77.7，两者有重叠，这是“非补偿门控＋补偿评分”的正常结果，报告中并列显示，并在反馈里指出导致Fail的检查点。

### 5.10 缺失、不适用与不完整

- **不适用**（如无需修正时的E4）：不计入，不算缺失。
- **缺测或记录中断**：沿用现行严格规则，正式结果不给最终概率与分数；已形成的证据可显示为不完整的过程结果，不补为D。
- 网络本身可以在缺少某条证据时给出更宽的后验，但正式结果仍按项目规则，避免非随机缺失（如中途坠毁）被当作随机缺失处理。

### 5.11 多模态扩展

眼动、语音按同样方式接入：先由规则形成检查点结果，再作为新的证据节点，配自己的a、b。生理信号没有条款依据，按项目规则只做诊断显示，不进入评分网络。

### 8.6 自我审查：风险与局限

1. **参数是设计值，不由数据标定。** a、b、ρ_day按文献锚点与设计原则设定，实采只用于敏感性与内部检验。按D-008与D-009，这是本项目的设计；产品中不写“已验证”。
2. **为什么不用65趟数据标定阈值b。** 用单一飞行员的65趟做IRT标定，θ的“总体”就成了这个人的趟间波动，检查点的“难度”会吸收他本人的弱项。例如E3只有4趟得D，标定后E3会变成“很难的检查点”，得U不再被认为是弱项，恰好抹掉了应该反馈给他的信息（R7）。共用阈值保留了这一信息：8.3节的检查点诊断正是由此得到。
3. **共用阈值假设各检查点的D/A/U含义相当。** 如果某检查点的D带定得特别严，会持续压低分数。处理方式是在检查点设计阶段核对D/A/U边界，而不是在网络里修正；Model Studio保留逐检查点修改a、b的能力。
4. **单次分数被压向中间。** 单次动作只有3～4条证据，全D给85.5分而不是100分，这是对不确定度的如实反映；报告用三档概率（高档0.97）和标准差说明。若希望单次分数更伸展，可提高a，但会让单条证据更强（a=2时全D为94.6分）。
5. **一阶自回归的均值回归。** 长期不训练时档案回到先验均值，对高水平飞行员表示“下降”，对低水平飞行员表示“上升”。本方案把它解释为“信息过期、回到未评估状态”，不表示方向性的技能衰退。文献显示停练后技能会下降（Arthur等1998；Wang等2013观察到长间隔后部分个体能力下降），但下降幅度缺少eVTOL模拟器数据依据，不设方向性衰退项。
6. **单一飞行员数据。** 跨次参数（同次训练内ρ=1）只来自一个人一天的65趟，其他人可能有更明显的学习或疲劳，参数可编辑。
7. **E4条件出现。** 无需修正的动作少一条证据。实采中E4的平均影响+0.3分，暂不需要处理；若后续认为“无需修正”本身应作为正面证据，可改为E4取最高档，但会与E3重复计入初次停住质量。
8. **五档证据依赖推拉次数的计数。** 计数对采样率敏感（8.3节），五档在证据规则定稿、并统一在原生采样率计算后启用。
9. **门控与分数可能看似矛盾。** Fail但50分、Pass但36分都会出现。这是设计意图（门控不可补偿、分数反映整体），报告与反馈需同时说明。
10. **暂不设跨科目的总体能力节点。** 科目之间的关联强度既无条款依据，也无法从现有数据估计（场景二只有8份完整记录，且保持段没有飞行员输入）。总体结果由“各科目P/F非补偿汇总＋各科目能力分＋检查点诊断按评价方面汇总”给出（R7）。

### 8.7 考虑过但不采用的做法

| 做法 | 不采用的原因 |
|---|---|
| 保留逐帧更新，调小α或CPT | 证据量仍随帧数增长，采样率问题不消失 |
| κ方案 | κ没有外部依据；三状态塌缩仍在；不给不确定度 |
| 用65趟标定a、b | 见8.6第2条 |
| 整段序列用HMM建模 | 已发表的版本都需要按熟练度分组的标注；证据仍随时长增长（文献调研第6节） |
| 训练神经网络 | 没有标签（D-008）；神经网络样式只用于说明网络结构（4.2节） |
| 跨科目高阶能力节点 | 见8.6第10条 |
| 连续θ（不离散） | 与9格点结果相同（J=41与J=9最多差1.3分），格点更便于在界面和汇报中展示 |

## 9. 导师汇报要点（R9、R10）

- **网络怎样构建：** 输入9路×100 Hz → 15个观测量 → 4个检查点证据（每个3档）→ 9个能力格点 → 能力分、标准差、低／中／高概率。权重由每个检查点的区分度和阈值生成。
- **信息融合：** 四个层次。通道融合（同一检查点结合多路信号，如E2结合杆量与减速度）；证据融合（多个检查点在能力层相加对数似然）；实例融合（重复实例共享能力）；时间融合（跨次档案按天衰减）。
- **更新频率：** 输入100 Hz；证据事件驱动，每次动作3～4次；档案每次训练一次，训练之间按天衰减。
- **技术挑战：** 100 Hz数据高度自相关，按帧计入会把同一证据重复数百次；没有外部评分标签，参数需由条款、文献与设计原则确定；检查点结果在不同时刻形成；门控不可补偿而评分需要综合；单次动作证据少，需要报告不确定度；眼动、语音、生理等新模态的接入方式。
