# Item 结果窗口与完整过程图实施计划

用户已给出期望图样并授权重做结果展示；随后明确选择“截至当前时刻的累计 item 分数，曲线终点与整段最终分数一致”。本轮直接实施这些要求，不重开设计审批。

## 产品结构

场景评估完成后，点击 item 的结果卡打开独立、可调整大小的结果窗口。主页面不再内联铺开全部过程图；参数编辑仍有独立按钮。Model Studio 的结果入口打开同一窗口。窗口持有评估时的配置、输入、目录和结果快照，之后工作区修改不改写旧报告。

窗口顶部显示场景/item、P/F、整段演示分数与完整累计分数曲线；下面按目录顺序排列检查点卡片。点击检查点展开其全部指标的完整时间过程。每张图单位独立，统一使用 item 的起止时间以便对照；期间不适用的阶段、缺失值不补齐或跨段连线。

按用户样图绘制黑色实际值线、期望虚线、绿色 Desired 内带和浅黄色 Acceptable 外带。线连接真实相邻观察以便阅读，不平滑造值。一般标量在原值坐标中显示目标及目标加各自的有符号允许偏差；角度使用相对目标展开的实际值避免 359° 到 1° 误画，明细保留原始角度。径向激光和路线距离使用相应距离坐标，明确脱靶而不编造距离。布尔检查单展示其真实时刻与状态。单帧显示点，不画一段虚构飞行。

检查点原始过程图为默认展开内容，不用近3秒概率线替代完整表现；旧 local_traces 数据保持兼容但不占据主要报告界面。方法说明收在折叠详情内。

## 累计分数合同

在每个 item 真实帧 t，对每个检查点统计截至 t 已观察的 D/A/U 数量并归一为 q。沿用现有先验、CPT、κ=3、固定检查点权重 1/K，从固定先验重新计算，不把上一后验再乘入；不使用3秒窗口，不因 phase 改变清空历史。

尚未出现的检查点没有证据，不填成 D，也不放大其他检查点的权重。界面显示已观察 n/K；不足 K 的累计估计为 partial，不能解释为完整 item 已通过。实际必需值缺失/非法后累计前缀失去完整性，不给出看似完整的后续分数。结构、参数或时序无效时不输出误导性曲线。最终完整报告的最后一个累计点必须与整段 posterior/score 一致；最终不完整时不提供有效终点分数。原规则 P/F 始终独立保留。

在 `skill_quantification` 增加可选 `cumulative_trace`，包含 item_id、method=`demo_cumulative_prefix_v1`、message、timeline。每点含 frame_index、timestamp_s、phase_id、status、observed_checkpoint_count、expected_checkpoint_count、missing_frame_count、posterior、score。旧报告无此字段时正常读取且不伪造曲线。
